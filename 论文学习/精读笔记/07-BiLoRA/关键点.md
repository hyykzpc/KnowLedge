

# VLM结合点
CLIP作为视觉语言模型提供无监督语义监督


# 解决的问题
一个在合成雾数据上训练好的去雾网络，怎么只利用没有GT的真实雾图像，低成本适配到真实世界

# 创新点

# H2C Loss

传统监督去雾需要现实场景的IGT,但现实场景没有
所以作者认为可以从有雾/清晰图片的语义上的变化方向着手，而CLIP恰好能提供此公共图文的latent space

使用neg和pos两段文本prompt得到两向量后再构造一个文本方向向量，代表有雾到清晰的过程的语义变化方向

图像方面，将真实有雾输入和去雾模型处理后图像都送入CLIP Image Encoder，得到向量，再经过计算得到模型实际造成的语义变化，代表预训练网络处理的“去雾”过程的语义变化方向

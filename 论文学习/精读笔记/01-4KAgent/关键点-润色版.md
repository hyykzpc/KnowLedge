# 4KAgent 关键点

> 核心定位：4KAgent 的创新不在于提出一个新的超分网络，而在于把已有 restoration experts 组织成一个可感知、可规划、可评估、可回滚的 agentic restoration workflow。

## 1. 一句话抓住论文

传统 SR 往往是：

$$
I_{\mathrm{LR}}
\xrightarrow{\text{single SR model}}
\hat I_{\mathrm{HR}}
$$

4KAgent 则把恢复过程改写为：

$$
I_0
\rightarrow
\text{Perception}
\rightarrow
P_I
\rightarrow
\text{Tool Execution}
\rightarrow
\text{Reflection}
\rightarrow
\text{Rollback if needed}
\rightarrow
I_K
$$

因此它更像一个“图像恢复调度系统”，而不是一个单独的像素生成模型。

## 2. 系统级结构

4KAgent 主要由四部分组成：

| 模块 | 作用 | 关键理解 |
|---|---|---|
| Profile Module | 系统配置层 | 决定是否追求 4K、是否做人脸恢复、偏向 fidelity 还是 perception |
| Perception Agent | 图像诊断与规划 | 用 IQA + VLM 判断内容、退化类型与任务顺序 |
| Restoration Agent | 工具执行与选择 | 调用多个 restoration experts，用 Q-MoE 选出当前最优结果 |
| Face Restoration Pipeline | 人脸专项修复 | 避免普通 SR 破坏身份、纹理和面部结构 |

这篇论文的系统视角是：不是训练一个“万能网络”，而是让 agent 学会使用一组专家模型。

## 3. Perception Agent

### 3.1 Image Analyzer

Image Analyzer 会运行多个 IQA 模型，得到一组质量指标，例如自然度、感知质量、清晰度等。这些数值不是最终答案，而是给 VLM 提供低层视觉上下文。

### 3.2 VLM Reasoning

VLM 接收原图和 IQA 指标，输出三类信息：

- 图像内容描述 $C_I$；
- 退化类型列表 $D_I$；
- 初步恢复议程 $A_I'$。

这里的 VLM 不是直接生成图像，而是回答：

$$
\text{图里有什么？哪里退化？需要哪些 restoration tasks？}
$$

### 3.3 Task Planning

Planner 会综合内容、退化列表、初步议程和经验库，生成有顺序的恢复计划：

$$
P_I=[T_1,T_2,\ldots,T_K]
$$

它把问题从：

$$
\text{一个网络同时解决所有退化}
$$

转成：

$$
\text{多个专家模型按计划组合解决}
$$

## 4. Restoration Agent

### 4.1 Tool Box

论文维护了多类 restoration tools，例如：

- brightening；
- defocus deblurring；
- motion deblurring；
- dehazing；
- denoising；
- deraining；
- JPEG artifact removal；
- super-resolution；
- face restoration。

每一类工具下又包含多个专家模型。

### 4.2 Q-MoE：质量驱动的专家选择

Q-MoE 与传统可训练 MoE 不同。它不是训练一个 gate 来选择专家，而是在推理时让一类工具下的多个专家都运行，再用质量评分选择最优输出：

$$
I_k
=
\arg\max_i
Q_s\!\left(T_i(I_{k-1})\right)
$$

论文中的质量评分可理解为：

$$
Q_s
=
H

\frac{Q_{nr}}{4}
$$

其中 $H$ 来自 HPSv2，$Q_{nr}$ 来自 NIQE、MUSIQ、MANIQA、CLIPIQA 等无参考 IQA 指标的组合。

重点：Q-MoE 的核心是 **Execution + Reflection**。它不只执行工具，还检查这一步是否真的让图像变好。

### 4.3 Reflection 与 Rollback

每一步恢复后，系统都会判断：

$$
Q_s(I_k)>\eta
$$

若成立，则继续下一步；否则触发 Rollback。

Rollback 回退的重点不是“把像素恢复原样”，而是把失败信息反馈给 Planner，让它重新调整任务顺序或任务选择：

$$
P_I^{\mathrm{adj}}
=
M_P(D_I,A_I^R,E,S_I)
$$

其中：

- $D_I$：原始退化判断；
- $A_I^R$：剩余恢复任务；
- $E$：经验库；
- $S_I$：失败信息。

这正是它像 Agent 的地方：它会根据执行结果修正计划，而不是盲目跑完固定 pipeline。

## 5. Face Restoration Pipeline

普通 SR 容易在人脸区域产生身份漂移、假纹理或不自然皮肤。4KAgent 会在需要时检测并裁剪人脸，调用多个 face restoration experts，再结合身份相似度和人脸质量指标选择结果。

这一步说明论文对“感知质量”做了对象级细化：整图质量最高，不一定代表人脸区域最可靠。

## 6. Profile Module

Profile 是系统配置层，决定：

- 是否自动到 4K；
- 放大倍率；
- 是否启用 face restoration；
- 是否启用 brightening；
- 偏向 Perception 还是 Fidelity。

它把“更真实”与“更好看”的取舍显式化：

$$
\text{Fidelity}
\neq
\text{Perceptual Quality}
$$

## 7. 最值得学习的创新思路

论文的思路变化是：

```text
设计更大的 CNN
设计更大的 Transformer
设计更强的 Diffusion SR
```

转向：

```text
我已经有很多强模型；
怎样让一个 Agent 知道何时用哪个模型、先后顺序是什么、结果是否可靠？
```

因此 4KAgent 真正值得迁移的思想是：

1. 用 VLM/IQA 做恢复前诊断；
2. 用 Planner 把低层恢复任务排序；
3. 用 Q-MoE 在多个专家结果中选优；
4. 用 Reflection 判断步骤是否成功；
5. 用 Rollback 防止错误恢复继续污染后续结果；
6. 用 Profile 将用户偏好和任务目标显式注入系统。

## 8. 批判性阅读

4KAgent 的风险也很清楚：

- $Q_s$ 高不等于真实细节正确，尤其 diffusion SR 可能生成“好看但不存在”的纹理；
- IQA 指标可能被模型迎合，产生 metric hacking；
- 每一步运行多个专家模型，成本高；
- “Any image to 4K” 依赖 toolbox 覆盖范围，不是数学意义上对所有退化都有保证；
- 医学、遥感、人脸等高风险场景中，清晰化结果必须标注为生成式增强，而不能当成事实恢复。

## 9. 最短记忆版

$$
\boxed{
\text{4KAgent}
=
\text{Profile}
+
\text{Perception}
+
\text{Planning}
+
\text{Q-MoE}
+
\text{Reflection/Rollback}
}
$$

一句话总结：

> 4KAgent 把超分从“一次前向推理”升级为“带诊断、工具调用、质量反思和失败回滚的闭环恢复系统”。

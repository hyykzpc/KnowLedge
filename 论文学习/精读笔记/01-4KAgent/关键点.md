# Preception Agent

1.Image Analyzer:运行多个IQA模型，得到多个评价指标，输送给VLM
2.VLM Mr 接收原图与评价指标，输出图像文本描述，图像退化列表，图像恢复计划
3.Planner VLM接收内容，退化列表，恢复计划以及恢复经验，设计恢复流程，即从从“一个网络同时解决”转成“多个专家模型按计划组合解决”

1.系统视角，设计一个完整的系统，针对传统SR可能会放大噪声的缺点进行改进
2.模块化视角，分为Profile Module、Perception Agent、Restoration Agent
同时有一个专门的Face Restoration Pipeline 

# Preception Agent

1.Image Analyzer:运行多个IQA模型，得到多个评价指标，输送给VLM
2.VLM Mr 接收原图与评价指标，输出图像文本描述，图像退化列表，图像恢复计划
3.Planner VLM接收内容，退化列表，恢复计划以及恢复经验，设计恢复流程，即从从“一个网络同时解决”转成“多个专家模型按计划组合解决”



# Restoration Agent
1.完整的Tool列表，共九类工具，每类工具下包含多个专家模型
2.Q-MoE（Execution+Reflection）：与传统MoE不同，他 一类工具下的每个专家模型都跑，并通过IQA打分的得到最优
3.Rollback：设定阈值，判断图像质量是否合格，不合格则让Planagent修改计划
4.Face Restoration：生成SR容易在人脸部分出问题，所以agent检测并裁剪人脸，然后跑多个 face restoration expert，再用新的评分

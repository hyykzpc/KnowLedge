# 解决的问题
1.当前LLIE中亮度与颜色没有真正解耦，很多深度学习方法中RGB信息仍然高度耦合
2.网络太大

# 核心思想
人工解析先验+极小神经网络融合+Retinex式残差
不直接把RGB丢入大网络，而是先计算两组特征（亮度先验和颜色先验）
而后经过两个很小的网络分别得到ΔL​ 和 ΔR​，最后有
\[ \boxed{ \hat I=I+\Delta_L\odot\Delta_R } \]


# 创新点
不做传统Retinex分解（\(I=L\odot R\)），不是非得准确恢复L和R
即不重建整张正常图像，只预测原图应该修改多少，再依据Retinex思想，对修改量进行分解


# 网络图理解
1.Multi-view Representation Construction
利用人工定义的解析公式把RGB变成容易被网络利用的先验
2.从I构建两个Guidance stack，构造两套更偏向“亮度”和“颜色”的描述量，让后面两个微型网络分别学习
3.SL：从四个角度分析亮度，即四张亮度图堆叠
4.SR：描述颜色，弱化绝对亮度影响，有三类五种图，即三组互补颜色线索
5.Fusion module:结构相同，参数不共享
5.1    1x1 conv 不进行空间邻域建模，主要进行通道混合
5.2     FB 空间信息+通道重要性，其中使用DSConv可以有更少的参数，MSEF则是Multi-Stage Squeeze & Excite Fusion，来自SE思想，MSFE查看了全局通道重要性和一些局部空间细节信息，整个FB模块解读为
第一个 MSEF：

\[ \boxed{\text{先判断当前各 channel 的价值}} \]

然后 DSConv：

\[ \boxed{\text{进行局部空间信息交换和特征融合}} \]

ReLU：

\[ \boxed{\text{引入非线性}} \]

第二个 MSEF：

\[ \boxed{\text{对融合之后的新 feature 再重新判断重要性}} \]

论文也是这样描述的：第一个 MSEF 利用全局上下文校准通道；DSConv + ReLU 做轻量空间 filtering；第二个 MSEF 再重新评估增强后的 activations。[arXiv](https://arxiv.org/html/2604.10359v1)

所以 FB 可以粗略概括成：

\[ \boxed{ \text{重标定} \rightarrow \text{局部融合} \rightarrow \text{再重标定} } \]


5.3 CWA目的是生成一张空间变换的特征聚合图
DWConv保证每种descirpotr的独立性，Conv则将prior对其到主分支

5.4 汇合后相乘，其中S代表网络提取出的内容，A代表这些内容应该被使用多少

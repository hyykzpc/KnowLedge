# 第3章 无监督学习 — 期末复习

## 核心摘要
- 无监督学习在无标签数据上发现结构，三大类问题：**聚类、降维、密度估计**
- **PCA** 是最经典的线性降维方法，通过最大化投影方差找到主成分，可通过对协方差矩阵做特征值分解求解
- **稀疏编码** 通过过完备基加稀疏约束学习数据的稀疏表示，目标是重构误差 + 稀疏惩罚
- **自编码器** 是神经网络版的非线性降维，通过 Encoder-Decoder 结构学习低维表示
- 自编码器家族：AE → 稀疏AE → 堆叠AE → 降噪AE → VAE，逐级改进表示能力

## 1. 无监督学习概述

### 1.1 定义与分类

**无监督学习（Unsupervised Learning）**：从无标签数据 $\{x^{(n)}\}_{n=1}^N$ 中发现结构。

| 类别 | 目标 | 代表方法 |
|------|------|----------|
| **聚类（Clustering）** | 将数据分组 | K-means、HAC |
| **降维（Dimensionality Reduction）** | 寻找低维表示 | PCA、自编码器 |
| **密度估计（Density Estimation）** | 估计 $p(x)$ | 直方图、KDE、参数法 |

### 1.2 无监督学习的应用

- **数据可视化**：将高维数据降到 2D/3D
- **特征学习/表示学习**：从无标签数据学习有用特征
- **异常检测**：低密度区域的样本可能是异常
- **数据压缩**：用低维表示节省存储
- **预训练**：无监督预训练 + 有监督微调

## 2. PCA 主成分分析（★★★ 核心推导）

### 2.1 核心思想

**PCA（Principal Component Analysis）**：找到数据方差最大的方向，将高维数据投影到低维子空间，**在损失最少信息的前提下降维**。

等价视角：
- **最大方差视角**：找到投影后方差最大的方向
- **最小重构误差视角**：找到使投影重构误差最小的方向

> **两个视角等价**，考试中通常采用最大方差视角。

### 2.2 问题形式化

给定中心化后的数据 $\{x^{(n)}\}_{n=1}^N$（即 $\sum x^{(n)} = 0$），寻找单位方向向量 $w$（$\|w\| = 1$），使投影 $y^{(n)} = w^T x^{(n)}$ 的方差最大。

**投影方差**：

$$
\begin{aligned}
\text{Var}(y) &= \frac{1}{N} \sum_{n=1}^N (y^{(n)} - \bar{y})^2 \\
&= \frac{1}{N} \sum_{n=1}^N (w^T x^{(n)} - w^T \bar{x})^2 \quad (\bar{x}=0 \text{ 中心化}) \\
&= \frac{1}{N} \sum_{n=1}^N (w^T x^{(n)})^2 \\
&= w^T \left( \frac{1}{N} \sum_{n=1}^N x^{(n)} (x^{(n)})^T \right) w \\
&= w^T \Sigma w
\end{aligned}
$$

其中 $\Sigma = \frac{1}{N} \sum_{n=1}^N x^{(n)} (x^{(n)})^T$ 是样本协方差矩阵。

**优化问题**：

$$
\max_{w} \; w^T \Sigma w \quad \text{s.t.} \quad w^T w = 1
$$

### 2.3 求解过程（Lagrange 乘子法）

构造 Lagrangian：

$$
\mathcal{L}(w, \lambda) = w^T \Sigma w - \lambda (w^T w - 1)
$$

对 $w$ 求导并令为 0：

$$
\frac{\partial \mathcal{L}}{\partial w} = 2\Sigma w - 2\lambda w = 0
$$

$$
\boxed{\Sigma w = \lambda w}
$$

这正是**特征值方程**！$w$ 是协方差矩阵 $\Sigma$ 的特征向量，$\lambda$ 是对应的特征值。

代入目标函数：

$$
w^T \Sigma w = w^T (\lambda w) = \lambda w^T w = \lambda
$$

**结论**：投影方差等于特征值 $\lambda$。最大方差方向对应最大特征值的特征向量。

### 2.4 PCA 算法步骤

```
输入: 数据 {x^(1), ..., x^(N)}，目标维度 K
1. 中心化: x^(n) ← x^(n) - x̄
2. 计算协方差矩阵: Σ = (1/N) Σ (x^(n))(x^(n))^T
3. 特征值分解: Σ = UΛU^T
4. 取前 K 大特征值对应的特征向量: w_1, ..., w_K
5. 投影: y^(n) = W^T x^(n)，其中 W = [w_1, ..., w_K]
输出: 降维后的数据 {y^(n)}
```

### 2.5 PCA 的意义

- **去相关**：投影后的各维度不相关（协方差矩阵是对角阵）
- **降噪**：舍弃小方差方向等价于去除噪声
- **压缩**：用更少的维度保留大部分信息
- **可视化**：降到 2D/3D 可展示数据结构

> **作业 2-七(2)**：对什么样的数据 PCA 反而会降低分类性能？
> 答：当数据的类别信息包含在**小方差方向**时，PCA 舍弃小方差方向会丢掉分类关键信息。例如两类数据的类间差异主要体现在方差较小的方向上，PCA 降维后反而使分类更困难。

### 2.6 PCA vs 线性判别分析（LDA）

| 方法 | 目标 | 是否使用标签 | 监督/无监督 |
|------|------|-------------|------------|
| PCA | 最大化投影方差 | 否 | 无监督 |
| LDA | 最大化类间/类内方差比 | 是 | 有监督 |

## 3. 稀疏编码（★★★ 作业2-八）

### 3.1 基本思想

**稀疏编码（Sparse Coding）**：用少量"基"的线性组合表示输入数据，要求**表示系数是稀疏的**。

给定过完备字典（基向量矩阵）$A = [a_1, \dots, a_M] \in \mathbb{R}^{D \times M}$，其中 $M > D$（过完备）：

$$
x \approx \sum_{i=1}^M a_i z_i = A z
$$

$x \in \mathbb{R}^D$ 是输入，$z \in \mathbb{R}^M$ 是编码（表示系数）。

### 3.2 目标函数

对一组输入 $\{x^{(n)}\}_{n=1}^N$，稀疏编码的目标函数为：

$$
\min_{A, \{z^{(n)}\}} \sum_{n=1}^N \left( \|x^{(n)} - A z^{(n)}\|^2 + \lambda \|z^{(n)}\|_1 \right)
$$

**两项含义**：
- $\|x - A z\|^2$：**重构误差**，保证编码能还原数据
- $\lambda \|z\|_1$：**稀疏正则项**（L1 范数），迫使大多数 $z_i = 0$

稀疏性度量函数的常用选择：

$$
\begin{aligned}
\ell(z) &= \|z\|_1 = \sum_{i=1}^M |z_i| \quad &\text{(L1 范数，最常用)} \\
\ell(z) &= \sum_{i=1}^M \log(1 + z_i^2) \quad &\text{(对数惩罚)} \\
\ell(z) &= \sum_{i=1}^M (1 - e^{-z_i^2}) \quad &\text{(指数惩罚)}
\end{aligned}
$$

### 3.3 训练过程

稀疏编码的训练交替优化两个变量（类似 EM 的坐标上升）：

```
1. 固定字典 A，优化编码 z^(n)（稀疏编码阶段）:
   对每个 x^(n)，求解 Lasso 问题:
   z^(n) = argmin_z ‖x^(n) - A z‖² + λ‖z‖₁

2. 固定编码 {z^(n)}，优化字典 A（字典学习阶段）:
   A = argmin_A Σ ‖x^(n) - A z^(n)‖²

3. 重复 1-2 直到收敛
```

### 3.4 线性编码表达式

**线性编码**：$z = W^T x$，其中 $W$ 是编码矩阵。

稀疏编码区别于 PCA 的关键：
- PCA：$z = W^T x$（线性编码），$W$ 的列是正交的
- 稀疏编码：$z$ 是稀疏的，字典 $A$ 过完备（$M > D$），编码矩阵和字典不要求正交

## 4. 自编码器（★★★ 作业2-九，核心）

### 4.1 基本自编码器（Auto-Encoder, AE）

**结构**：Encoder → 低维表示（瓶颈层）→ Decoder

```
输入 x  →  [Encoder]  →  z（低维编码）  →  [Decoder]  →  重构 x̂
```

- **Encoder**：$z = f_\phi(x)$，将高维输入映射到低维表示
- **Decoder**：$\hat{x} = g_\theta(z)$，从低维表示重构输入

**学习目标**：最小化重构误差

$$
\mathcal{L} = \sum_{n=1}^N \|x^{(n)} - g_\theta(f_\phi(x^{(n)}))\|^2
$$

或带权重衰减（正则化）：

$$
\mathcal{L} = \sum_{n=1}^N \|x^{(n)} - g_\theta(f_\phi(x^{(n)}))\|^2 + \lambda \|W\|^2
$$

**与 PCA 的关系**：线性自编码器（无激活函数、单层）的最优解等价于 PCA。但自编码器可以通过非线性激活函数和深度结构学习**非线性流形**，比 PCA 表达能力更强。

**瓶颈结构**：隐层维度 $d_z < d_x$，迫使模型学习压缩表示。

### 4.2 稀疏自编码器（Sparse Auto-Encoder）

在 AE 基础上增加对编码 $z$ 的稀疏约束：

$$
\mathcal{L} = \sum_{n=1}^N \left( \|x^{(n)} - \hat{x}^{(n)}\|^2 + \lambda \sum_{j=1}^{d_z} \text{KL}(\rho \| \bar{\rho}_j) \right) + \beta \|W\|^2
$$

其中 $\bar{\rho}_j = \frac{1}{N} \sum_{n=1}^N [z_j^{(n)}]$ 是第 $j$ 个神经元的平均激活率，$\rho$ 是目标稀疏率（通常为 0.05 左右），$\text{KL}(\rho \| \bar{\rho})$ 是 KL 散度惩罚。

**即使隐层维度 $d_z \geq d_x$，稀疏约束仍能学到有意义的表示**——这是稀疏自编码器区别于普通 AE 的关键。

### 4.3 堆叠自编码器（Stacked Auto-Encoder, SAE）

**结构**：将多个自编码器逐层堆叠。

**训练方式——逐层预训练（Layer-Wise Training）**：

```
1. 训练第1个AE: x → h₁ → x̂₁
2. 固定第1层，取 h₁ 作为输入训练第2个AE: h₁ → h₂ → ĥ₁
3. 固定第2层，取 h₂ 作为输入训练第3个AE: h₂ → h₃ → ĥ₂
4. ... 重复直到所有层训练完毕
5. （可选）所有层预训练完成后，整体微调（Fine-tuning）
```

**权重绑定（Tied Weight）**：编码器和解码器的权重矩阵互为转置 $W^{(2)} = (W^{(1)})^T$，可减少参数量、起到正则化作用。

### 4.4 降噪自编码器（Denoising Auto-Encoder, DAE）

**核心思想**：向输入加入噪声，让自编码器学习从受损输入中恢复原始数据。

```
加噪: x̃ = x + ε（或随机遮罩部分维度）
编码: z = f(x̃)
解码: x̂ = g(z)
目标: min ‖x - x̂‖²   （用原始 x 与重构 x̂ 计算损失）
```

**意义**：DAE 迫使编码器提取对噪声鲁棒的稳健特征，学习到的表示更具泛化能力。

### 4.5 变分自编码器（VAE）

VAE 详细推导见 [[02 Learning/生成模型 - 第13章学习笔记]]，此处仅列考试核心。

**VAE vs AE 的本质区别**：

| 维度 | AE | VAE |
|------|-----|-----|
| 编码输出 | 确定性向量 $z$ | 概率分布参数 $(\mu, \sigma)$ |
| 隐空间结构 | 无约束 | 约束为 $\mathcal{N}(0, I)$ |
| 能否生成新样本 | 不能（仅压缩） | 能（从先验采样） |
| 损失函数 | 重构误差 | 重构误差 + KL 散度 |

**VAE 的核心损失函数**：

$$
\mathcal{L}_{\text{VAE}} = -\underbrace{\mathbb{E}_{q(z|x)}[\log p(x|z)]}_{\text{重构损失}} + \underbrace{\text{KL}(q(z|x) \| p(z))}_{\text{KL 正则项}}
$$

### 4.6 自编码器家族对比

| 模型 | 核心改进 | 学习目标 |
|------|----------|----------|
| AE | 基本 Encoder-Decoder 结构 | $\min \|x - \hat{x}\|^2$ |
| 稀疏AE | 加稀疏约束 | $\min \|x - \hat{x}\|^2 + \lambda \cdot \text{sparsity}(z)$ |
| 堆叠AE | 多层逐层训练 | 多个 AE 逐层预训练 |
| 降噪AE | 输入加噪声 | $\min \|x - g(f(\tilde{x}))\|^2$ |
| VAE | 变分推断 + 重参数化 | $\min [-\mathbb{E}[\log p(x|z)] + \text{KL}(q\|p)]$ |

## 5. 聚类方法

### 5.1 K-means

**算法步骤**：

```
1. 随机选取 K 个簇中心
2. 重复直到收敛:
   a. 每个样本分配到最近的簇中心
   b. 更新簇中心为簇内样本均值
```

**目标函数**：

$$
\min_{\{c_k\}} \sum_{k=1}^K \sum_{x^{(n)} \in C_k} \|x^{(n)} - c_k\|^2
$$

**局限**：
- 需预先指定 $K$
- 对初始簇中心敏感
- 假设各簇是球形的
- 对异常值敏感

### 5.2 层次聚类（HAC）

- **自底向上**（凝聚式）：每个样本自成一簇，逐次合并最近的两个簇
- **自顶向下**（分裂式）：所有样本为一簇，逐次分裂

## 6. 密度估计

### 6.1 参数法

假设数据服从某已知分布（如 Gaussian），估计分布参数（如 MLE）。

### 6.2 非参数法

| 方法 | 思路 | 优点 | 缺点 |
|------|------|------|------|
| **直方图法** | 将数据分箱，统计频率 | 简单 | 受 bin 大小影响大 |
| **KDE（核密度估计）** | 在每个样本处放一个核函数 $K(\cdot)$，叠加估计密度 $\hat{p}(x) = \frac{1}{N} \sum K(x - x^{(n)})$ | 平滑，无需假设分布 | 计算量大 |

## 7. 自监督学习

**核心思想**：构造代理任务（Proxy Tasks），从无标签数据自动生成标签。

**NLP 中的经典自监督任务**：
- **词预测（Word Prediction）**：根据上下文预测被遮罩的词（如 BERT 的 Masked LM）
- **句子顺序预测**：判断两个句子是否连续
- **下一句预测**

**CV 中的经典自监督任务**：
- **拼图（Jigsaw）**：将图像分成 patch 后打乱，预测正确顺序
- **图像着色（Colorization）**：从灰度图预测彩色图
- **图像修补（In-painting）**：遮罩部分区域，预测缺失内容

## 8. 半监督学习

利用少量标注数据 + 大量无标签数据提升性能。

**关键假设**：
- **平滑假设**：相近的样本有相似标签
- **聚类假设**：同一簇的样本共享标签
- **流形假设**：高维数据位于低维流形上

**代表方法**——自训练（Self-Training）：用标注数据训练模型，预测无标签数据，将高置信度预测加入训练集，迭代重复。

## 9. 关键公式速查

| 公式 | 含义 |
|------|------|
| $\Sigma = \frac{1}{N} \sum (x^{(n)})(x^{(n)})^T$ | 协方差矩阵 |
| $\Sigma w = \lambda w$ | PCA 的特征值方程 |
| $y = W^T x$ | PCA 投影（$W$ 为前 K 个特征向量） |
| $\min \|x - A z\|^2 + \lambda \|z\|_1$ | 稀疏编码目标函数 |
| $\min \|x - g_\theta(f_\phi(x))\|^2$ | 自编码器目标函数 |
| $\min \|x - g(f(\tilde{x}))\|^2$ | 降噪自编码器目标函数 |
| $\min [-\mathbb{E}_{q}[\log p(x|z)] + \text{KL}(q\|p)]$ | VAE 损失函数 |
| $\min \sum \|x^{(n)} - c_k\|^2$ | K-means 目标函数 |
| $\hat{p}(x) = \frac{1}{N} \sum K(x - x^{(n)})$ | KDE 密度估计 |

## 关键结论

1. **无监督学习**三大类：聚类、降维、密度估计
2. **PCA** 的核心是协方差矩阵的特征值分解，最大特征值对应最大方差方向
3. **PCA 与 LDA 的区别**：PCA 无监督（最大化方差），LDA 有监督（最大化类间/类内比）
4. **自编码器**是非线性降维工具，线性 AE 等价于 PCA
5. **稀疏编码**的关键是 L1 正则化产生稀疏表示，过完备字典带来更大表达能力
6. 自编码器家族的演进趋势：更强的正则化 → 更鲁棒的表示

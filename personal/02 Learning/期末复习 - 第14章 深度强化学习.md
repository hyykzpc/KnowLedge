# 第14章 深度强化学习 — 期末复习

## 核心摘要
- **强化学习（RL）**：智能体通过与环境交互、最大化累积奖励的序列决策范式
- **MDP**：RL 的数学框架，核心是马尔可夫性——未来只依赖当前状态和动作
- **值函数** $V_\pi(s)$ 和 $Q_\pi(s,a)$ 评估策略优劣，满足 **Bellman 方程**（递归关系）
- **深度 RL** 用神经网络近似值函数或策略，代表方法：**DQN**（值函数）、**Policy Gradient**（策略优化）、**Actor-Critic**（二者融合）
- 核心挑战：**探索 vs 利用**（Exploration vs Exploitation）

## 1. 强化学习基础

### 1.1 核心要素

| 要素 | 符号 | 说明 |
|------|------|------|
| 状态 | $s \in \mathcal{S}$ | 环境的描述 |
| 动作 | $a \in \mathcal{A}$ | 智能体的行为 |
| 策略 | $\pi(a\|s)$ | 状态到动作的映射（确定型或随机型） |
| 奖励 | $r \in \mathcal{R}$ | 环境对动作的即时反馈（RL 唯一的学习信号）|
| 状态转移 | $P(s'\|s,a)$ | 环境动态 |

### 1.2 马尔可夫决策过程（MDP）

**MDP 元组** $(\mathcal{S}, \mathcal{A}, P, r, \gamma)$

**马尔可夫性**：下一时刻状态仅依赖当前状态和动作，与历史无关：
$$P(s_{t+1} \mid s_t, a_t, s_{t-1}, a_{t-1}, \dots) = P(s_{t+1} \mid s_t, a_t)$$

**轨迹（Trajectory）** 的概率分解：
$$P(\tau) = P(s_0) \prod_{t=0}^{T-1} \pi(a_t \mid s_t) P(s_{t+1} \mid s_t, a_t)$$

**折扣累积回报**：
$$G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}, \quad \gamma \in [0, 1)$$

$\gamma$ 控制远见程度：$\gamma \to 0$ 短视（只看即时奖励），$\gamma \to 1$ 远视。

## 2. 值函数与 Bellman 方程（★★★）

### 2.1 值函数定义

**状态值函数** $V_\pi(s)$：从 $s$ 出发，按 $\pi$ 行动的期望回报
$$V_\pi(s) = \mathbb{E}_\pi[G_t \mid s_t = s]$$

**状态-动作值函数** $Q_\pi(s,a)$：从 $s$ 执行 $a$，之后按 $\pi$ 行动的期望回报
$$Q_\pi(s, a) = \mathbb{E}_\pi[G_t \mid s_t = s, a_t = a]$$

**两者关系**：
$$V_\pi(s) = \sum_a \pi(a \mid s) Q_\pi(s, a)$$

### 2.2 Bellman 方程推导

**$V_\pi$ 的 Bellman 方程**：
$$
\begin{aligned}
V_\pi(s) &= \mathbb{E}_\pi[G_t \mid s_t = s] \\
&= \mathbb{E}_\pi[r_{t+1} + \gamma G_{t+1} \mid s_t = s] \\
&= \sum_a \pi(a \mid s) \sum_{s'} P(s' \mid s, a) \big[ r(s, a, s') + \gamma V_\pi(s') \big]
\end{aligned}
$$

**核心思想**：当前状态的值 = 即时奖励 + 折扣后的下一状态值，称为 **Bootstrapping**（用估计估计估计）。

**$Q_\pi$ 的 Bellman 方程**：
$$Q_\pi(s, a) = \sum_{s'} P(s' \mid s, a) \left[ r(s, a, s') + \gamma \sum_{a'} \pi(a' \mid s') Q_\pi(s', a') \right]$$

### 2.3 Bellman 最优方程

最优值函数 $V_*(s) = \max_\pi V_\pi(s)$ 满足：
$$V_*(s) = \max_a \sum_{s'} P(s' \mid s, a) \big[ r(s, a, s') + \gamma V_*(s') \big]$$

最优 Q 函数：
$$Q_*(s, a) = \sum_{s'} P(s' \mid s, a) \left[ r(s, a, s') + \gamma \max_{a'} Q_*(s', a') \right]$$

**策略提取**：$\pi_*(s) = \arg\max_a Q_*(s, a)$

---

## 3. 基于模型的 RL（规划）

### 3.1 策略迭代

1. **策略评估**：固定 $\pi$，迭代求解 $V_\pi(s)$（求解 Bellman 方程）
2. **策略改进**：$\pi'(s) = \arg\max_a Q_\pi(s, a)$（贪心提升）

**策略改进定理**：只要 $Q_\pi(s, \pi'(s)) \geq V_\pi(s)$ 对所有 $s$ 成立，则 $\pi' \geq \pi$。

### 3.2 值迭代

直接迭代 Bellman 最优方程：
$$V_{k+1}(s) = \max_a \sum_{s'} P(s' \mid s, a) \big[ r(s, a, s') + \gamma V_k(s') \big]$$

| 方法 | 收敛速度 | 每步开销 | 适用场景 |
|------|---------|---------|---------|
| 策略迭代 | 快（多项式级） | 大（需完整策略评估） | 状态空间小 |
| 值迭代 | 慢（线性收敛） | 小（单步更新） | 状态空间大 |

## 4. 免模型 RL（Model-Free）

### 4.1 蒙特卡洛（MC）方法

用完整轨迹的平均回报估计 $Q$：
$$Q(s,a) \approx \frac{1}{N} \sum_{i=1}^N G^{(i)}(s,a)$$

**优点**：无偏；**缺点**：方差大，仅适用于 episodic 任务。

### 4.2 时序差分学习（TD）

结合 MC 采样 + DP Bootstrapping：
$$Q(s,a) \leftarrow Q(s,a) + \alpha \big( \underbrace{r + \gamma Q(s',a')}_{\text{TD Target}} - Q(s,a) \big)$$

**TD 误差** $\delta = r + \gamma Q(s',a') - Q(s,a)$：衡量实际观测与当前估计的偏差。

### 4.3 SARSA vs Q-Learning（★★★ 必考对比）

| 特性 | **SARSA** | **Q-Learning** |
|------|-----------|----------------|
| 类型 | **On-policy** | **Off-policy** |
| TD Target | $r + \gamma Q(s', a')$（策略采样的 $a'$） | $r + \gamma \max_{a'} Q(s', a')$（贪心 $a'$） |
| 学习对象 | 当前策略的值函数 | **最优 Q 函数** |
| 行为特点 | 保守（考虑探索风险） | 激进（假设未来最优） |

**更新公式对比**：
- SARSA：$Q(s,a) \leftarrow Q(s,a) + \alpha(r + \gamma Q(s',a') - Q(s,a))$
- Q-Learning：$Q(s,a) \leftarrow Q(s,a) + \alpha(r + \gamma \max_{a'} Q(s',a') - Q(s,a))$

---

## 5. 深度 Q 网络（DQN）（★★★）

### 5.1 值函数近似

当状态空间太大（如原始像素），用神经网络 $Q(s,a;\theta)$ 近似 Q 函数。

### 5.2 目标函数

最小化 Bellman 误差（MSE）：
$$\mathcal{L}(\theta) = \mathbb{E}_{(s,a,r,s') \sim \mathcal{D}} \left[ \big( \underbrace{r + \gamma \max_{a'} Q(s', a'; \theta^-)}_{\text{TD Target}} - Q(s, a; \theta) \big)^2 \right]$$

### 5.3 两个核心创新

**1. 目标网络（Target Network）**：
- 使用固定的 $\theta^-$ 计算 TD Target
- 每 $C$ 步同步 $\theta^- = \theta$
- 打破 target 与估计的耦合，防止发散

**2. 经验回放（Experience Replay）**：
- 将 $(s,a,r,s')$ 存入回放缓冲区 $\mathcal{D}$
- 随机采样 mini-batch 训练
- 打破样本间时间相关性，减少方差

### 5.4 探索策略：$\varepsilon$-贪心

$$\pi(a \mid s) = \begin{cases}
1 - \varepsilon + \frac{\varepsilon}{|\mathcal{A}|}, & a = \arg\max Q(s,a') \\
\frac{\varepsilon}{|\mathcal{A}|}, & \text{otherwise}
\end{cases}$$

$\varepsilon$ 从 1.0 退火衰减至 0.1 左右。

## 6. 策略梯度（Policy Gradient）（★★★）

### 6.1 核心思想

直接优化策略 $\pi_\theta(a \mid s)$，最大化期望回报：
$$J(\theta) = \mathbb{E}_\tau[G(\tau)] = \int P(\tau;\theta) G(\tau) d\tau$$

### 6.2 策略梯度定理推导

$$\begin{aligned}
\nabla_\theta J(\theta) &= \int \nabla_\theta P(\tau;\theta) G(\tau) d\tau \\
&= \int P(\tau;\theta) \frac{\nabla_\theta P(\tau;\theta)}{P(\tau;\theta)} G(\tau) d\tau \quad \text{(乘以)} \\
&= \int P(\tau;\theta) \nabla_\theta \log P(\tau;\theta) G(\tau) d\tau \quad \text{(对数导数：} \nabla\log f = \frac{\nabla f}{f}) \\
&= \mathbb{E}_\tau[ G(\tau) \nabla_\theta \log P(\tau;\theta) ]
\end{aligned}$$

### 6.3 轨迹概率展开

$$\log P(\tau;\theta) = \cancel{\log P(s_0)} + \sum_{t=0}^{T-1} \log \pi_\theta(a_t|s_t) + \cancel{\sum_{t=0}^{T-1} \log P(s_{t+1}|s_t,a_t)}$$

环境动态与 $\theta$ 无关，梯度为零，可消去。代入得：
$$\boxed{\nabla_\theta J(\theta) = \mathbb{E}_\tau \left[ \sum_{t=0}^{T-1} G(\tau) \nabla_\theta \log \pi_\theta(a_t \mid s_t) \right]}$$

### 6.4 REINFORCE 算法

1. 用 $\pi_\theta$ 采样轨迹 $\tau$
2. 对每个 $t$，计算 $G_t = \sum_{k=t}^{T-1} \gamma^{k-t} r_{k+1}$
3. $\theta \leftarrow \theta + \alpha G_t \nabla_\theta \log \pi_\theta(a_t \mid s_t)$

**无偏但高方差**——单条轨迹回报波动大。

### 6.5 基线降方差（Baseline）

引入 $b(s)$（通常取 $V_\pi(s)$）：
$$\nabla_\theta J(\theta) = \mathbb{E}\left[ \sum_t (G_t - b(s_t)) \nabla_\theta \log \pi_\theta(a_t \mid s_t) \right]$$

**基线不改变期望**：$\mathbb{E}[b(s) \nabla_\theta \log \pi_\theta(a|s)] = b(s) \cdot \mathbb{E}[\nabla_\theta \log \pi_\theta(a|s)] = b(s) \cdot 0 = 0$，因为 $\int \pi_\theta(a|s) da = 1$ 的梯度为零。

---

## 7. Actor-Critic 算法（★★★）

### 7.1 核心思想

融合值函数（低方差）和策略梯度（直接优化策略）：

- **Actor（演员）**：策略网络 $\pi_\theta(a \mid s)$，负责选动作
- **Critic（评论家）**：值函数网络 $V_\phi(s)$（或 $Q_\phi(s,a)$），评估动作好坏

### 7.2 Actor 更新公式

用 **TD 误差** $\delta = r + \gamma V_\phi(s') - V_\phi(s)$ 替代 $G_t - b(s_t)$：
$$\nabla_\theta J(\theta) = \mathbb{E}[\delta \nabla_\theta \log \pi_\theta(a \mid s)]$$

### 7.3 Critic 损失函数

$$\mathcal{L}(\phi) = (r + \gamma V_\phi(s') - V_\phi(s))^2$$

### 7.4 方法对比总结

| 方法 | 类型 | 关键更新公式 | 特点 |
|------|------|-------------|------|
| 策略迭代 | 模型已知 | Bellman eq. + 贪心改进 | 收敛快、开销大 |
| 值迭代 | 模型已知 | $V_{k+1}(s) = \max_a \mathbb{E}[r + \gamma V_k(s')]$ | 收敛慢、开销小 |
| SARSA | 免模型 | On-policy TD: $r + \gamma Q(s',a')$ | 保守 |
| Q-Learning | 免模型 | Off-policy TD: $r + \gamma \max Q(s',a')$ | 激进 |
| **DQN** | 免模型 + 深度 | $(r + \gamma \max Q(s';\theta^-) - Q(s;\theta))^2$ | 目标网络 + 经验回放 |
| **REINFORCE** | 策略梯度 | $\nabla J = \mathbb{E}[G_t \nabla \log \pi]$ | 无偏、高方差 |
| **Actor-Critic** | 融合 | $\nabla J = \mathbb{E}[\delta \nabla \log \pi]$ | 低方差、有偏 |

## 8. 关键公式速查

| 公式 | 含义 |
|------|------|
| $G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}$ | 折扣累积回报 |
| $V_\pi(s) = \mathbb{E}_\pi[G_t \mid s_t = s]$ | 状态值函数 |
| $Q_\pi(s,a) = \mathbb{E}_\pi[G_t \mid s_t = s, a_t = a]$ | 状态-动作值函数 |
| $V_\pi(s) = \sum_a \pi(a\|s) Q_\pi(s,a)$ | $V$ 与 $Q$ 的关系 |
| $V_\pi(s) = \sum_a \pi(a\|s) \sum_{s'} P(s'\|s,a)[r + \gamma V_\pi(s')]$ | **Bellman 方程** |
| $V_*(s) = \max_a \sum_{s'} P(s'\|s,a)[r + \gamma V_*(s')]$ | Bellman 最优方程 |
| $\delta = r + \gamma Q(s',a') - Q(s,a)$ | TD 误差 |
| $\mathcal{L}_{\text{DQN}} = \mathbb{E}[(r + \gamma \max Q(s';\theta^-) - Q(s;\theta))^2]$ | DQN 损失函数 |
| $\nabla_\theta J = \mathbb{E}_\tau[\sum_t G_t \nabla_\theta \log \pi_\theta(a_t\|s_t)]$ | **策略梯度定理** |
| $\nabla_\theta J = \mathbb{E}[\delta \nabla_\theta \log \pi_\theta(a\|s)]$ | Actor-Critic 更新 |

## 关键结论

1. **MDP 核心假设**：马尔可夫性——未来只依赖当前 $s$ 和 $a$
2. **Bellman 方程**：RL 的"勾股定理"，递归分解值函数，是所有算法的理论基础
3. **On-policy vs Off-policy**：前者用当前策略采样的数据学习（SARSA），后者可用历史数据（Q-Learning）
4. **DQN 两大创新**：目标网络（固定 target 防发散）+ 经验回放（打破相关性降方差）
5. **策略梯度核心技巧**：对数导数 $\nabla \log \pi$ 将不可微的期望目标转为可采样形式
6. **Actor-Critic**：TD 误差（低方差）+ 策略梯度（直接优化），现代深度 RL 的基座

# 生成模型

## 核心摘要
- 生成模型（Generative Model）学习数据的联合分布 $p(x, y)$ 或边缘分布 $p(x)$，能生成符合分布的新样本
- VAE 通过变分推断近似隐变量后验，用 ELBO 作为可优化目标，结合重参数化技巧实现端到端训练
- GAN 通过生成器与判别器的零和博弈（Minimax Game）隐式学习数据分布，无需显式密度估计
- 两类模型的核心权衡：VAE 有显式似然目标但样本偏模糊，GAN 样本清晰但训练不稳定、易模式崩溃
- Wasserstein GAN（W-GAN）用 Earth Mover 距离替代 JS 散度，从根本上改善了 GAN 的训练稳定性

## 解决的问题
- 学习高维观测数据（图像、文本、音频）背后的真实分布 $p_{\text{data}}(x)$
- 从学习到的分布中采样生成新样本
- 密度估计、数据增强、表示学习、缺失值填补、异常检测
- 区别于判别模型 $p(y|x)$：生成模型捕捉数据本身的**产生过程**

---

## 核心概念

### 1. 生成模型概述

#### 1.1 生成问题

给定观测数据 $\mathcal{D} = \{x^{(i)}\}_{i=1}^N$，假设来自未知分布 $p_{\text{data}}(x)$，生成模型的目标：

1. **密度估计**：学习一个模型 $p(x;\theta)$ 逼近 $p_{\text{data}}(x)$
2. **样本生成**：从 $p(x;\theta)$ 采样新样本

#### 1.2 生成模型分类

| 分类维度 | 类型 | 代表模型 |
|---------|------|---------|
| 密度估计方式 | 显式密度模型（Explicit） | VAE、PixelRNN、Flow-based |
| | 隐式密度模型（Implicit） | GAN |
| 是否有隐变量 | 隐变量模型 | VAE、GAN（隐式） |
| | 无隐变量模型 | PixelCNN、NADE |

#### 1.3 生成模型 vs 判别模型

| 维度    | 生成模型               | 判别模型 |     |
| ----- | ------------------ | ---- | --- |
| 建模目标  | $p(x, y)$ 或 $p(x)$ | $p(y | x)$ |
| 能力    | 生成 + 判别            | 仅判别  |     |
| 计算复杂度 | 较高                 | 较低   |     |
| 数据效率  | 可无监督学习             | 需标注  |     |

> **我的理解**：生成模型回答"数据如何产生"，判别模型回答"给定数据，标签是什么"。生成模型通常更难，因为它需要捕捉数据完整的概率结构。

### 2. 变分自编码器（VAE）

#### 2.1 问题形式化

观测变量 $x$，隐变量 $z$，生成过程：

$$
p(x, z;\theta) = p(x|z;\theta)p(z;\theta), \quad p(z;\theta) = \mathcal{N}(z; 0, I)
$$

目标是最大化边际对数似然：

$$
\log p(x;\theta) = \log \int p(x,z;\theta) dz
$$

直接优化困难——积分在高维隐空间不可解。

#### 2.2 ELBO 推导

引入变分后验 $q(z|x;\phi)$（编码器）近似真实后验 $p(z|x;\theta)$：

$$
\log p(x;\theta) = \mathcal{L}(q, \theta, x) + \text{KL}(q(z|x;\phi) \| p(z|x;\theta))
$$

其中 ELBO：

$$
\mathcal{L}(q, \theta, x) = \mathbb{E}_{q(z|x;\phi)}[\log p(x|z;\theta)] - \text{KL}(q(z|x;\phi) \| p(z;\theta))
$$

> **我的理解**：ELBO 的两项有清晰的分工——第一项是**重构损失**（解码器能从 $z$ 重建 $x$ 吗？），第二项是**正则项**（后验 $q(z|x)$ 不要偏离先验 $p(z)$ 太远）。这两项天然互斥：过于强调重构会让 $q(z|x)$ 坍塌为 delta 分布（KL 变大），过于强调 KL 会让 $z$ 忽略 $x$ 的信息（重构变差）。

#### 2.3 VAE 网络结构

- **编码器**（Encoder / Recognition Model）：$q(z|x;\phi) = \mathcal{N}(z; \mu_\phi(x), \sigma^2_\phi(x))$
- **解码器**（Decoder / Generative Model）：$p(x|z;\theta)$

编码器输出均值和方差，而非直接输出 $z$——这是为了通过重参数化技巧保持可微性。

#### 2.4 重参数化技巧（Reparameterization Trick）

核心问题：$z \sim q(z|x;\phi)$ 是采样操作，不可导。

解决方案：

$$
z = \mu_\phi(x) + \sigma_\phi(x) \odot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)
$$

将随机性转移到外部噪声 $\epsilon$，使梯度可以通过 $\mu$ 和 $\sigma$ 传播。

> **我的理解**：重参数化是 VAE 的"发动机"。没有它，我们不能对采样过程求导，VAE 就退化为普通的 EM 或 MCMC。它将随机节点移出计算图的"关键路径"——在反向传播中，$\epsilon$ 是常数，$\mu$ 和 $\sigma$ 是确定性函数，梯度可以自由流动。

#### 2.5 损失函数

$$
\mathcal{L}_{\text{VAE}} = -\underbrace{\mathbb{E}_{q(z|x;\phi)}[\log p(x|z;\theta)]}_{\text{重构损失}} + \underbrace{\text{KL}(q(z|x;\phi) \| p(z;\theta))}_{\text{KL 正则项}}
$$

KL 项有闭式解（两个高斯分布之间）：

$$
\text{KL}(\mathcal{N}(\mu, \sigma^2) \| \mathcal{N}(0, I)) = \frac{1}{2}\left(\text{tr}(\sigma^2) + \mu^\top\mu - d - \log|\sigma^2|\right)
$$

#### 2.6 VAE 的训练流程

```
输入: 数据集 D = {x^(1), ..., x^(N)}
1. 采样 x^(i) ~ D
2. 编码器计算 μ = Encoder_μ(x^(i)), σ = Encoder_σ(x^(i))
3. 重参数化: z = μ + σ ⊙ ε, ε ~ N(0, I)
4. 解码器重构: x̂ = Decoder(z)
5. 计算损失: L_rec + L_KL
6. 反向传播更新 φ (编码器) 和 θ (解码器)
```

#### 2.7 条件变分自编码器（CVAE）

在编码器和解码器中加入条件 $c$（如类别标签）：

$$
\log p(x|c;\theta) \geq \mathbb{E}_{q(z|x,c;\phi)}[\log p(x|z,c;\theta)] - \text{KL}(q(z|x,c;\phi) \| p(z|c;\theta))
$$

> **我的理解**：CVAE 的条件 $c$ 相当于告诉模型"在这种条件下生成怎样的数据"。这比无条件生成更容易控制——比如指定数字类别生成 MNIST 图像。条件信息在编码器和解码器中都注入，等价于在学习**类别条件分布** $p(x|c)$。

#### 2.8 VAE 的局限

- 生成样本偏模糊（因为 Gaussian 似然假设 + 平均所有可能的输出）
- ELBO 是似然的下界而非精确值，优化存在偏差
- 隐空间的后验坍缩（Posterior Collapse）问题——尤其在强解码器下（如自回归解码器）

### 3. 生成对抗网络（GAN）

#### 3.1 核心思想

两个网络进行零和博弈：

- **生成器** $G(z;\theta_g)$：从随机噪声 $z \sim p(z)$ 生成假样本
- **判别器** $D(x;\theta_d)$：区分真实样本和生成样本

目标函数（Minimax Game）：

$$
\min_{\theta_g} \max_{\theta_d} V(D, G) = \mathbb{E}_{x \sim p_{\text{data}}}[\log D(x)] + \mathbb{E}_{z \sim p(z)}[\log(1 - D(G(z)))]
$$

> **我的理解**：GAN 的博弈可以类比"伪造者 vs 鉴定专家"——生成器是伪造者，判别器是鉴定师。伪造者试图做出更逼真的赝品，鉴定师努力辨别真伪。理想平衡点是：判别器无法区分（$D = 0.5$），生成器完美捕捉了真实分布。这个类比也解释了 GAN 训练的本质困难——双方必须势均力敌。

#### 3.2 判别器的优化

固定生成器 $G$，最优判别器：

$$
D^*(x) = \frac{p_{\text{data}}(x)}{p_{\text{data}}(x) + p_g(x)}
$$

代入目标函数后得到：

$$
V(G, D^*) = 2\, \text{JS}(p_{\text{data}} \| p_g) - 2\log 2
$$

其中 $\text{JS}$ 是 Jensen-Shannon 散度。因此 GAN 的全局最优解是 $p_g = p_{\text{data}}$。

#### 3.3 训练算法

```
输入: 真实数据分布 p_data, 噪声分布 p(z)
1. 初始化生成器 G(·; θ_g) 和判别器 D(·; θ_d)
2. for 训练迭代次数 do
3.   for k 步 do             // 训练判别器
4.     采样 {z^(1),...,z^(m)} ~ p(z)
5.     采样 {x^(1),...,x^(m)} ~ p_data
6.     梯度上升更新 θ_d:
7.       ∇[1/m Σ(log D(x^(i)) + log(1 - D(G(z^(i)))))]
8.   end
9.   采样 {z^(1),...,z^(m)} ~ p(z)  // 训练生成器
10.  梯度下降更新 θ_g:
11.     ∇[1/m Σ log(1 - D(G(z^(i))))]
12. end
```

> **我的理解**：训练 GAN 需要交替更新 $D$ 和 $G$，但 $D$ 的更新频率通常更高（$k$ 步对 1 步），因为需要先让 $D$ 足够强才能给 $G$ 提供有效梯度。如果 $D$ 太弱，$G$ 的梯度信号是噪声；如果 $D$ 太强（完美区分），$G$ 的梯度会消失。

#### 3.4 DCGAN

DCGAN 是 GAN + CNN 的里程碑工作，关键架构设计：

1. 去除全连接层和池化层，使用**转置卷积**（Transposed Convolution）上采样
2. 生成器使用 ReLU（最后一层 Tanh），判别器使用 LeakyReLU
3. 使用批归一化（Batch Normalization）稳定训练
4. 典型结构：100维噪声 → $4 \times 4 \times 1024$ 特征图 → $64 \times 64$ 图像

#### 3.5 GAN 训练的困难与改进

##### 3.5.1 模式崩溃（Mode Collapse）

生成器只生成有限几种样本（"骗过判别器就行"）。

**数学原因**：生成器的梯度来自 $\log(1 - D(G(z)))$，当 $D$ 分类准确时梯度消失。改进版本使用 $\min -\mathbb{E}[\log D(G(z))]$ 提供更强梯度。

##### 3.5.2 不收敛问题

博弈双方的优化方向可能震荡，不像标准损失函数单调下降。

##### 3.5.3 前向 KL vs 反向 KL

| 散度 | 公式 | 行为特点 |
|------|------|---------|
| 前向 KL | $\text{KL}(p_{\text{data}} \| p_g) = \int p_{\text{data}} \log \frac{p_{\text{data}}}{p_g}$ | 覆盖数据所有模式（均值-seeking） |
| 反向 KL | $\text{KL}(p_g \| p_{\text{data}}) = \int p_g \log \frac{p_g}{p_{\text{data}}}$ | 只拟合一个模式（模式-seeking） |

原始 GAN 等价于优化反向 KL，这是模式崩溃的理论根源。

> **我的理解**：前向 KL 中 $p_{\text{data}} > 0$ 的地方 $p_g$ 必须覆盖（不覆盖则 KL → ∞），所以生成结果偏"发散"；反向 KL 中 $p_g$ 集中在 $p_{\text{data}}$ 的某个模式上即可（其他区域反正 $p_g = 0$ 不会受罚），所以生成结果偏"单一但逼真"。VAE 优化前向 KL（通过 ELBO），GAN 优化反向 KL——这解释了 VAE 样本模糊但多样，GAN 样本清晰但单一的困境。

### 4. Wasserstein GAN（W-GAN）

#### 4.1 Earth Mover（Wasserstein-1）距离

$$
W_1(p_{\text{data}}, p_g) = \inf_{\gamma \in \Pi(p_{\text{data}}, p_g)} \mathbb{E}_{(x, y) \sim \gamma}[\|x - y\|]
$$

直观理解：将 $p_{\text{data}}$ 的"土堆"搬到 $p_g$ 的最小工作量。

**与 KL/JS 的关键区别**：
- KL/JS 在分布无重叠时是常数（梯度为零）
- Wasserstein 距离即使在分布不重叠时仍能提供有意义的梯度

> **我的理解**：这是 W-GAN 的"魔法"。当真实分布和生成分布在高维空间中几乎不重叠时（训练初期），JS 散度是常数 $\log 2$，梯度消失。但 Wasserstein 距离仍然平滑变化，提供"往哪个方向走能更接近真实分布"的信号。

#### 4.2 Kantorovich-Rubinstein 对偶

将 $W_1$ 转化为可计算形式：

$$
W_1(p_{\text{data}}, p_g) = \frac{1}{K} \sup_{\|f\|_L \leq K} \left( \mathbb{E}_{x \sim p_{\text{data}}}[f(x)] - \mathbb{E}_{x \sim p_g}[f(x)] \right)
$$

其中 $f$ 需满足 $K$-Lipschitz 连续：$|f(x_1) - f(x_2)| \leq K\|x_1 - x_2\|$。

#### 4.3 W-GAN 的关键改动

| 原始 GAN | W-GAN |
|---------|-------|
| 判别器输出概率（sigmoid） | 评论家（Critic）输出实数分数 |
| JS 散度 | Wasserstein-1 距离 |
| 判别器需平衡生成器 | 评论家可训练至最优 |
| 梯度消失 | 梯度始终有意义 |
| 优化 $\min \log(1-D)$ | 优化 $\min - \mathbb{E}_{z}[f(G(z))]$ |

**Lipschitz 约束的实现**：权重裁剪（Weight Clipping），将评论家参数限制在 $[-c, c]$ 范围内。

#### 4.4 W-GAN 训练算法

```
输入: 真实数据分布 p_data, 噪声分布 p(z)
1. 初始化生成器 G 和评论家 f_w
2. for 训练迭代次数 do
3.   for t = 1 to n_critic do
4.     采样 {z^(i)} ~ p(z), {x^(i)} ~ p_data
5.     g_w ← ∇_w[1/m Σ(f_w(x^(i)) - f_w(G(z^(i))))]
6.     w ← w + α · RMSProp(w, g_w)     // RMSProp 优化
7.     w ← clip(w, -c, c)               // 权重裁剪
8.   end
9.   采样 {z^(i)} ~ p(z)
10.  g_θ ← -∇_θ[1/m Σ f_w(G(z^(i)))]   // 生成器损失
11.  θ ← θ - α · RMSProp(θ, g_θ)
12. end
```

### 5. VAE vs GAN 对比

| 维度 | VAE | GAN |
|------|-----|-----|
| 目标函数 | 最大化 ELBO（似然下界） | Minimax 博弈 |
| 密度估计 | 显式（有向图模型） | 隐式 |
| 训练稳定性 | 稳定，损失单调下降 | 不稳定，需仔细平衡 |
| 样本质量 | 偏模糊 | 清晰锐利 |
| 模式覆盖 | 好（覆盖所有模式） | 差（易模式崩溃） |
| 隐空间 | 有意义的隐空间（连续、可插值） | 隐空间难以直接解释 |
| 推理 | 天然支持（$q(z|x)$） | 需额外训练推理网络 |

> **我的理解**：VAE 和 GAN 的差异本质上是**显式密度 vs 隐式密度**和**前向 KL vs 反向 KL**的双重叠加。VAE 保证了覆盖所有模式的"安全"生成，代价是模糊；GAN 牺牲了全局覆盖换取了局部真实性。近年来 VQ-VAE、扩散模型等一定程度上弥合了这一鸿沟。

## 关键结论

1. 生成模型分为显式密度模型（VAE）和隐式密度模型（GAN），前者有可优化的似然目标，后者通过博弈隐式学习
2. VAE 的核心贡献是**重参数化技巧**，使采样过程可微，开启深度生成模型的端到端训练
3. ELBO 是重构损失与 KL 正则项的权衡，两项天然互斥
4. GAN 的博弈结构等价于最小化 JS 散度，全局最优解是 $p_g = p_{\text{data}}$
5. **模式崩溃**是 GAN 的根本困难，源于反向 KL 散度的特性
6. W-GAN 用 Wasserstein 距离替代 JS 散度，从根本上改善了梯度信号，稳定性远优于原始 GAN
7. VAE 与 GAN 的优劣互补催生了 VAE-GAN、扩散模型等混合方法

## 矛盾与不确定性
- VAE 的模糊输出是否必然？β-VAE 等变体证明增大 KL 权重可提升解耦表示但降低重构质量
- 扩散模型（DDPM）在样本质量上已超越 GAN，但其多步采样效率远低于 GAN 的单步生成
- W-GAN 的权重裁剪过于粗糙，梯度惩罚（Gradient Penalty, WGAN-GP）提供了更优雅的 Lipschitz 约束方案

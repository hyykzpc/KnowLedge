# 第4章 注意力机制与外部记忆 — 期末复习

## 核心摘要
- 注意力机制的核心思想是从大量输入中选择性地聚焦重要信息，通过加权聚合实现"软寻址"
- **注意力打分函数**有 4 种：加性模型、点积模型、双线性模型、缩放点积模型（Transformer 使用）
- **QKV 自注意力**是 Transformer 的核心：$A = \text{softmax}(Q^T K / \sqrt{d_k})$，输出 $H = V A^T$
- **多头注意力**将 Q/K/V 投影到多个子空间并行计算，拼接后融合，捕捉不同关系模式
- **Transformer** 由编码器（自注意力 + FFN）和解码器（掩码自注意力 + 交叉注意力 + FFN）堆叠而成
- **外部记忆**（NTM、Hopfield 网络）将注意力扩展为可微读写操作

## 1. 注意力机制概述

### 1.1 核心思想

**生物直觉**：人处理视觉信号时，不会同时关注全部信息，而是选择性地聚焦于某一部分。

**计算定义**：给定输入向量序列 $X = [x_1, \dots, x_N]$ 和查询向量 $q$，注意力机制计算所有位置与 $q$ 的相关性，按相关性加权聚合信息：

$$
\begin{aligned}
\alpha_n &= \text{softmax}(s(x_n, q)) = \frac{\exp(s(x_n, q))}{\sum_{j=1}^N \exp(s(x_j, q))}, \\
\text{att}(X, q) &= \sum_{n=1}^N \alpha_n x_n
\end{aligned}
$$

其中 $\alpha_n$ 是**注意力分布**（权重），$s(x_n, q)$ 是**注意力打分函数**。

本质：**软寻址**——$q$ 作为查询检索 $X$ 中的信息，返回所有 $x_n$ 的加权平均。

---

### 1.2 注意力打分函数（4 种）

| 类型 | 公式 | 参数量 | 特点 |
|------|------|--------|------|
| **加性模型** | $s(x,q) = v^T \tanh(Wx + Uq)$ | 高 | 可建模非线性交互（Bahdanau Attention） |
| **点积模型** | $s(x,q) = x^T q$ | 无 | 简单高效，要求 $x,q$ 同维 |
| **双线性模型** | $s(x,q) = x^T W q$ | 中 | $W$ 可学习不同维度间交互 |
| **缩放点积模型** | $s(x,q) = \frac{x^T q}{\sqrt{d}}$ | 无 | **点积的改进**，避免高维 softmax 梯度消失 |

> **为什么缩放点积需要除以 $\sqrt{d}$？**
> 设 $x, q \in \mathbb{R}^d$ 各分量独立同分布、均值 0、方差 1，则点积 $x^T q$ 的方差为 $d$。$d$ 越大，点积数值越大，softmax 越容易进入梯度极小的饱和区（接近 one-hot）。除以 $\sqrt{d}$ 后方差回归 1，梯度更稳定。

### 1.3 软注意力 vs 硬注意力（作业 3 潜在考点）

| 类型 | 计算方式 | 可微性 | 训练方法 |
|------|---------|--------|---------|
| **软注意力（Soft Attention）** | 加权求和所有输入 | **可微** | 端到端 BP |
| **硬注意力（Hard Attention）** | 选择单一输入位置（$\arg\max$） | **不可微** | 强化学习 / 蒙特卡洛 |

- 软注意力是"软寻址"——对所有存储单元加权求和
- 硬注意力是"硬选择"——只选择最相关的一个位置，更节省计算但训练困难

## 2. 键值对注意力（★★★ 作业3-一核心）

### 2.1 普通模式（标准注意力）

输入 $X = [x_1, \dots, x_N]$，查询 $q$：

$$
\text{att}(X, q) = \sum_{n=1}^N \alpha_n x_n,\quad \alpha_n = \frac{\exp(s(x_n, q))}{\sum_j \exp(s(x_j, q))}
$$

- $X$ 同时扮演"被关注的对象"和"被读取的内容"
- 适用：$X$ 自身就是需要被读取的值

### 2.2 键值对模式（Key-Value Attention）

将输入分为键 $K = [k_1, \dots, k_N]$ 和值 $V = [v_1, \dots, v_N]$：

$$
\text{att}((K, V), q) = \sum_{n=1}^N \frac{\exp(s(k_n, q))}{\sum_j \exp(s(k_j, q))} v_n
$$

**关键设计**：
- **键（Key）**：与 $q$ 计算相关性，决定"关注哪些位置"
- **值（Value）**：被加权求和的内容，决定"读取什么信息"

**键值分离的意义**：模型可以独立控制"寻址方式"（Key）和"读取内容"（Value），类似字典的 key → value 映射。Transformer 中 $K$ 和 $V$ 来自同一序列但经过不同投影矩阵，正是此思想的体现。

---

## 3. QKV 自注意力模型（★★★ 作业3-三核心推导）

### 3.1 QKV 形式化

给定输入序列 $X = [x_1, \dots, x_N] \in \mathbb{R}^{d \times N}$，通过三个投影矩阵得到：

$$
Q = W_q X \in \mathbb{R}^{d_k \times N},\quad K = W_k X \in \mathbb{R}^{d_k \times N},\quad V = W_v X \in \mathbb{R}^{d_v \times N}
$$

**缩放点积注意力**：

$$
\boxed{\text{SelfAttention}(X) = \text{softmax}\left(\frac{Q^T K}{\sqrt{d_k}}\right) V}
$$

### 3.2 计算流程（作业3-三：画出计算过程）

```
输入 X ∈ ℝ^{d×N}
    ↓
Step 1: 投影 → Q = W_q X, K = W_k X, V = W_v X
    ↓
Step 2: 计算相似度矩阵 → S = Q^T K ∈ ℝ^{N×N}
    ↓
Step 3: 缩放 → S' = S / √d_k
    ↓
Step 4: Softmax 归一化 → A = softmax(S') ∈ ℝ^{N×N}（注意力权重矩阵）
    ↓
Step 5: 加权求和 → H = A V ∈ ℝ^{N×d_v}
    ↓
输出: 上下文融合后的表示 H
```

### 3.3 单步计算图解

以第 $i$ 个位置为例：

1. 查询：$q_i = W_q x_i$
2. 第 $i$ 个位置对所有位置的注意力分数：$s_{ij} = q_i^T k_j / \sqrt{d_k}$
3. 归一化权重：$\alpha_{ij} = \exp(s_{ij}) / \sum_{t=1}^N \exp(s_{it})$
4. 输出：$h_i = \sum_{j=1}^N \alpha_{ij} v_j$

每个位置的输出是所有位置 Value 的加权和，权重由 Query 与所有 Key 的相似度决定。

### 3.4 自注意力的"自"体现在哪？

$Q, K, V$ 都来自同一个 $X$，即序列内部做注意力——每个位置作为查询去检索所有其他位置的信息，在序列内部建立**全连接图**。

### 3.5 自注意力 vs 全连接层（作业3-四：对比）

| 维度 | 全连接层（FC） | 自注意力（Self-Attention） |
|------|---------------|--------------------------|
| 权重 | 固定的参数矩阵 $W$ | **动态生成**的注意力权重 $\alpha_{ij}$ |
| 输入依赖 | 权重与输入无关 | 权重依赖输入内容（**动态权重**） |
| 感受野 | 固定（通常只连接单个位置） | **全局**（每个位置关注所有位置） |
| 参数量 | $d \times d'$ | $d_k \times d \times 3$（Q/K/V 投影）+ 动态权重 |
| 序列长度适应性 | 固定输入维度 | **可变序列长度** |
| 位置感知 | 否（permutation invariant） | 否（需额外加位置编码） |

**核心区别**：自注意力的权重 $\alpha_{ij} = \text{softmax}(q_i^T k_j / \sqrt{d_k})$ 是**输入依赖的**（data-dependent），而 FC 的权重是固定的。

## 4. 多头注意力（Multi-Head Attention）

### 4.1 定义

将 Q/K/V 投影到 $M$ 个不同的子空间，独立计算注意力后拼接融合：

$$
\text{MultiHead}((K,V), q) = \text{Concat}(\text{head}_1, \dots, \text{head}_M) W_O
$$

其中每个头：

$$
\text{head}_m = \text{Attention}(W_m^{(Q)} q, W_m^{(K)} K, W_m^{(V)} V) = \text{softmax}\left(\frac{(W_m^{(Q)} q)^T (W_m^{(K)} K)}{\sqrt{d_k}}\right) (W_m^{(V)} V)
$$

### 4.2 多头机制的意义

- **子空间并行**：每个头在不同投影子空间学习不同的注意力模式（语法关系、语义依赖等）
- **集成学习效果**：多组注意力结果互补，比单头表达能力更强
- 默认参数：$d_{\text{model}} = 512$, $n_{\text{heads}} = 8$, 每头 $d_k = d_{\text{model}} / n_{\text{heads}} = 64$

---

## 5. 位置编码（Positional Encoding）

### 5.1 为什么要位置编码？

自注意力是**置换不变**（Permutation Invariant）的——打乱输入顺序，输出仅对应打乱。为了利用序列顺序信息，必须注入位置编码。

### 5.2 正余弦位置编码（Transformer）

$$
\begin{aligned}
PE_{(pos, 2i)} &= \sin(pos / 10000^{2i/d_{\text{model}}}) \\
PE_{(pos, 2i+1)} &= \cos(pos / 10000^{2i/d_{\text{model}}})
\end{aligned}
$$

其中 $pos$ 是位置，$i$ 是维度索引。

**设计原理**：
- 不同频率：低频维度编码远距离信息，高频维度编码近距离信息
- 线性变换性质：对任意偏移 $k$，$PE_{pos+k}$ 可表示为 $PE_{pos}$ 的线性变换，使模型能学到相对位置关系

## 6. Transformer 完整架构（★★★ 作业4-2(1) 核心）

### 6.1 整体结构

```
输入序列
    ↓ Embedding + Positional Encoding
┌──────────────────────┐
│  Encoder × N         │
│  ┌────────────────┐  │
│  │ Self-Attention  │  │  ← q = k = v = encoder input
│  │ + Residual+LN  │  │
│  ├────────────────┤  │
│  │ FeedForward    │  │
│  │ + Residual+LN  │  │
│  └────────────────┘  │
└──────────┬───────────┘
           ↓ memory (编码器最终输出)
           │
目标序列 ──┤
    ↓ Embedding + Positional Encoding
┌──────────────────────┐
│  Decoder × N         │
│  ┌────────────────┐  │
│  │ Masked Self-   │  │  ← 因果掩码，防止看到未来 token
│  │ Attention      │  │
│  │ + Residual+LN  │  │
│  ├────────────────┤  │
│  │ Cross-         │  │  ← q = decoder output, k = v = memory
│  │ Attention      │  │
│  │ + Residual+LN  │  │
│  ├────────────────┤  │
│  │ FeedForward    │  │
│  │ + Residual+LN  │  │
│  └────────────────┘  │
└──────────┬───────────┘
           ↓
    Linear → 输出 logits
```

### 6.2 编码器（Encoder）

由 $N$ 个相同的 EncoderLayer 堆叠（原论文 $N=6$），每层含两个子层：

1. **多头自注意力**：$q = k = v = \text{encoder\_input}$，每个位置关注编码器所有位置
2. **前馈网络（FFN）**：$\text{FFN}(x) = W_2 \cdot \text{ReLU}(W_1 x + b_1) + b_2$，升维 $d_{\text{model}} \to d_{ff} \to d_{\text{model}}$（$d_{ff} = 2048$）

每个子层后接：**残差连接** + **层归一化**（LayerNorm）：
$$x = \text{LayerNorm}(x + \text{Sublayer}(x))$$

### 6.3 解码器（Decoder）

由 $N$ 个相同的 DecoderLayer 堆叠，每层含三个子层：

1. **掩码多头自注意力**：$q = k = v = \text{decoder\_input}$，使用**因果掩码**（下三角矩阵），位置 $i$ 只能看到 $j \leq i$ 的位置
2. **交叉注意力（Cross-Attention）**：$q = \text{decoder output}$，$k = v = \text{memory}$（编码器输出），解码器关注源语言序列
3. **前馈网络**：同编码器

### 6.4 训练与推理

| 阶段 | 解码器输入 | 关键点 |
|------|-----------|--------|
| **训练（Teacher Forcing）** | 真实目标序列 | 并行计算，用因果掩码防泄露 |
| **推理（自回归解码）** | 上一步输出作为当前步输入 | 逐个生成，<eos> 停止 |

**Teacher Forcing**：训练时将真实目标序列作为解码器输入（而非上一步预测），加速收敛。

## 7. 指针网络（Pointer Network）（★★☆ 作业3-二）

### 7.1 核心思想

指针网络的输出不是固定词表上的分类，而是**直接指向输入序列中的某个位置**：

$$
p(y_i | y_{<i}, X) = \text{softmax}(v^T \tanh(W h_j + U s_i))
$$

### 7.2 与注意力的关系

- 标准注意力：输出 $\sum \alpha_n x_n$（**加权求和**）
- 指针网络：输出 $y_i = \arg\max \alpha_i$（**直接选位置**）

将注意力权重 $\alpha$ 直接解释为输出概率分布，用于输出词汇表由输入序列动态决定的场景（如 TSP 等组合优化问题、抽取式摘要）。

## 8. 外部记忆与记忆增强网络（★★☆ 作业3-五）

### 8.1 神经图灵机（NTM, Neural Turing Machine）

通过可微分读写操作实现类似图灵机的计算能力：

```
控制器（Controller）
    ↕ （通过注意力寻址）
记忆矩阵 M = [m_1, ..., m_K]
```

**读操作**：生成查询 $q$，计算注意力权重 $\alpha = \text{softmax}(q^T m_k)$，输出读取向量：
$$r = \sum_{k=1}^K \alpha_k m_k$$

**写操作**：结合**擦除向量** $e_t$ 和**添加向量** $a_t$：
$$\tilde{m}_k = m_k (1 - \alpha_k e_t) + \alpha_k a_t$$

### 8.2 端到端记忆网络（MemN2N）

支持**多跳推理**（Multi-Hop），将上一步输出作为下一步查询：

$$u^{(1)} = q,\quad u^{(k+1)} = u^{(k)} + o^{(k)}$$

每跳从不同记忆片段读取，适合多步推理任务。

## 9. Hopfield 网络（★★☆ 作业3-六）

### 9.1 基本概念

Hopfield 网络是一种具有**能量函数**的循环神经网络，通过能量最小化实现联想记忆。

### 9.2 能量函数

$$E = -\frac{1}{2} x^T W x - b^T x$$

### 9.3 更新规则（异步）

$$x_i^{(t+1)} = \text{sign}\left(\sum_{j} W_{ij} x_j^{(t)} + b_i\right)$$

### 9.4 Hebbian 学习规则（存储记忆）

$$W = \frac{1}{P} \sum_{p=1}^P x^{(p)} (x^{(p)})^T$$

### 9.5 与注意力的联系（扩展了解）

Ramsauer et al. (2020) 证明：Transformer 的自注意力 $\text{softmax}(\beta Q K^T) V$ 等价于带温度参数的 Hopfield 网络能量函数的梯度更新——注意力是在能量景观中向存储模式收敛的过程。

## 10. 关键公式速查

| 公式 | 含义 |
|------|------|
| $\alpha_n = \frac{\exp(s(x_n, q))}{\sum_j \exp(s(x_j, q))}$ | 注意力分布（softmax 归一化权重） |
| $s(x,q) = v^T \tanh(Wx + Uq)$ | 加性注意力打分函数 |
| $s(x,q) = \frac{x^T q}{\sqrt{d}}$ | 缩放点积注意力打分函数 |
| $\text{SelfAttention}(X) = \text{softmax}(Q^T K / \sqrt{d_k}) V$ | QKV 自注意力核心公式 |
| $\text{MultiHead} = \text{Concat}(\text{head}_1, \dots, \text{head}_M) W_O$ | 多头注意力拼接融合 |

| $W = \frac{1}{P} \sum x^{(p)} (x^{(p)})^T$ | Hebbian 学习规则 |

## 关键结论

1. **注意力机制本质**：软寻址 + 加权聚合，$\alpha$ 定义了"关注什么"
2. **缩放因子 $\sqrt{d_k}$**：控制点积方差，避免高维 softmax 梯度消失
3. **键值分离**：$K$ 决定关注位置，$V$ 决定读取内容，独立控制寻址与取值
4. **自注意力 vs 全连接**：自注意力的权重是**动态生成**的（data-dependent），FC 权重固定
5. **多头 = 子空间并行**：不同头捕捉不同关系模式，拼接融合
6. **Transformer 编码器**：自注意力 → FFN，每个位置融合全局信息
7. **Transformer 解码器**：掩码自注意力 → 交叉注意力 → FFN，防未来泄露，连接源目标
8. **残差连接 + LayerNorm**：让深层 Transformer 稳定训练的标准设计
9. **NTM**：通过可微读写和注意力寻址实现类似图灵机的计算
10. **Hopfield 网络**：能量景观联想记忆，与自注意力存在深层数学联系

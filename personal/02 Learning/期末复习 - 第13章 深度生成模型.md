# 第13章 深度生成模型 — 期末复习

## 核心摘要
- 生成模型学习联合分布 $p(x, y)$ 或边缘分布 $p(x)$，能生成新样本；判别模型学习条件分布 $p(y|x)$
- **VAE**：通过变分推断 + 重参数化技巧最大化 ELBO，显式密度估计，样本模糊但模式覆盖好
- **GAN**：生成器与判别器零和博弈，隐式密度估计，样本清晰但易模式崩溃
- **W-GAN**：用 Wasserstein 距离替代 JS 散度，解决梯度消失，训练更稳定
- **扩散模型**（Diffusion Model）：正向逐步加噪破坏数据，反向逐步去噪生成，当前 SOTA

## 1. 判别式 AI vs 生成式 AI（★★★ 作业4-1）

**判别式 AI** 回答"这是什么？"——学习决策边界 $p(y|x)$，直接对输入分类或预测。

**生成式 AI** 回答"能创造什么？"——学习数据分布 $p(x)$ 或 $p(x,y)$，生成新样本。

| 维度 | 判别模型 | 生成模型 |
|------|---------|---------|
| **建模目标** | $p(y\|x)$ 条件分布 | $p(x,y)$ 或 $p(x)$ 联合/边缘分布 |
| **能力** | **分类/判别** | **生成 + 判别**（贝叶斯规则） |
| **计算量** | 较小 | 较大 |
| **数据需求** | 需标注 | 可无监督 |
| **代表模型** | 感知机、LR、SVM、CNN、RNN、**Transformer 编码器** | VAE、GAN、**扩散模型**、**NBE**、PixelRNN |

**学过的判别模型（作业4-1 要求列举至少 10 种）**：
1. 感知机（Perceptron）
2. 逻辑回归（Logistic Regression）
3. 支持向量机（SVM）
4. 决策树 / 随机森林
5. K 近邻（K-NN）
6. 朴素贝叶斯
7. 前馈神经网络（FNN）
8. 卷积神经网络（CNN）
9. 循环神经网络（RNN / LSTM / GRU）
10. Transformer（仅编码器或分类头）
11. 线性判别分析（LDA）
12. 条件随机场（CRF）

## 2. 变分自编码器（VAE）（★★★ 作业4-2(2) 核心）

### 2.1 问题形式化

观测变量 $x$，隐变量 $z$，目标是最大化边际对数似然：

$$\log p(x;\theta) = \log \int p(x|z;\theta) p(z) dz$$

直接优化困难——积分在高维隐空间不可解。

### 2.2 VAE 架构

```
编码器（推断网络）                    解码器（生成网络）
x → [Encoder] → μ, σ → z = μ + σ⊙ε → [Decoder] → x̂
                     ↑ 重参数化
                 ε ∼ 𝒩(0, I)
```

- **编码器** $q(z|x;\phi)$：输出后验分布的均值 $\mu_\phi(x)$ 和方差 $\sigma_\phi^2(x)$
- **解码器** $p(x|z;\theta)$：从隐变量 $z$ 重构 $x$
- **重参数化技巧**：$z = \mu + \sigma \odot \epsilon$, $\epsilon \sim \mathcal{N}(0, I)$

### 2.3 损失函数（ELBO）

$$\boxed{\mathcal{L}_{\text{VAE}} = -\underbrace{\mathbb{E}_{q(z|x;\phi)}[\log p(x|z;\theta)]}_{\text{重构损失}} + \underbrace{\text{KL}(q(z|x;\phi) \| p(z))}_{\text{KL 正则项}}}$$

**两项含义**：
- **重构损失**：解码器能否从 $z$ 重建 $x$（似然）
- **KL 正则项**：后验 $q(z|x)$ 不要偏离先验 $p(z) = \mathcal{N}(0, I)$ 太远

**KL 项闭式解**（两高斯间）：
$$\text{KL}(\mathcal{N}(\mu, \sigma^2) \| \mathcal{N}(0, I)) = \frac{1}{2}(\mu^T\mu + \text{tr}(\sigma^2) - d - \log|\sigma^2|)$$

### 2.4 重参数化技巧的意义

**问题**：$z \sim q(z|x;\phi)$ 是采样操作，不可导。

**解决**：将随机性转移到外部噪声 $\epsilon$：
$$z = \mu_\phi(x) + \sigma_\phi(x) \odot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$

梯度可通过 $\mu$ 和 $\sigma$ 传播（$\epsilon$ 视为常数），实现端到端 BP 训练。

### 2.5 VAE vs AE

| 维度 | AE | VAE |
|------|-----|-----|
| 编码输出 | 确定性向量 $z$ | 分布参数 $(\mu, \sigma)$ |
| 隐空间 | 无约束 | 约束为 $\mathcal{N}(0, I)$ |
| 能否生成 | 不能（仅压缩） | 能（从先验采样解码） |
| 损失函数 | $\|x - \hat{x}\|^2$ | 重构损失 + KL 散度 |

## 3. 生成对抗网络（GAN）（★★★ 作业4-2(3) 核心）

### 3.1 架构与原理

两个网络零和博弈：

- **生成器** $G(z;\theta_g)$：从随机噪声 $z \sim p(z)$ 生成假样本
- **判别器** $D(x;\theta_d)$：区分真实样本和生成样本

```
随机噪声 z → [Generator] → 假样本 G(z)
                              ↕ 判别器 D → 真/假？
真实数据 x → ──────────────→ 
```

### 3.2 Minimax 目标函数

$$\boxed{\min_{\theta_g} \max_{\theta_d} V(D, G) = \mathbb{E}_{x \sim p_{\text{data}}}[\log D(x)] + \mathbb{E}_{z \sim p(z)}[\log(1 - D(G(z)))]}$$

**直观理解**：
- 判别器 $D$ 想最大化 $\log D(x)$（真实判真）+ $\log(1 - D(G(z)))$（假判假）
- 生成器 $G$ 想最小化 $\log(1 - D(G(z)))$（让判别器认不出假样本）

### 3.3 最优判别器

固定 $G$，最大化 $V(D, G)$ 得到最优判别器：

$$D^*(x) = \frac{p_{\text{data}}(x)}{p_{\text{data}}(x) + p_g(x)}$$

**代入 $D^*$ 后目标函数**：
$$V(G, D^*) = 2 \cdot \text{JS}(p_{\text{data}} \| p_g) - 2\log 2$$

**全局最优解**：$p_g = p_{\text{data}}$，此时 $D^* = 0.5$，$V = -2\log 2$。

### 3.4 训练过程

```
for 训练迭代 do
    for k 步 do                     // 训练判别器
        采样 {z^(1..m)} ~ p(z), {x^(1..m)} ~ p_data
        梯度上升更新 θ_d: ∇[log D(x) + log(1 - D(G(z)))]
    end
    采样 {z^(1..m)} ~ p(z)          // 训练生成器
    梯度下降更新 θ_g: ∇[log(1 - D(G(z)))]     （或 ∇[-log D(G(z))]）
end
```

**技巧**：实践中常用 $\min -\mathbb{E}[\log D(G(z))]$ 替代 $\min \log(1 - D(G(z)))$，提供更强的梯度信号。

### 3.5 DCGAN

GAN + CNN，关键设计：
- 去除全连接层和池化层，使用**转置卷积**上采样
- 生成器：ReLU（最后一层 Tanh），判别器：LeakyReLU
- 批归一化（Batch Normalization）稳定训练

### 3.6 GAN 的核心困难

**模式崩溃（Mode Collapse）**：生成器只生成有限几种样本。

**原因**：GAN 等价于优化**反向 KL** $\text{KL}(p_g \| p_{\text{data}})$。反向 KL 在 $p_g=0$ 区域不受罚，生成器可忽略部分模式（只拟合一个或几个模式即可得高分）。

| 散度 | 方向 | 行为 |
|------|------|------|
| **前向 KL** $\text{KL}(p_{\text{data}}\|p_g)$ | $p_{\text{data}} > 0$ 区域 $p_g$ 必须覆盖 | **均值-seeking**（覆盖所有模式） |
| **反向 KL** $\text{KL}(p_g\|p_{\text{data}})$ | $p_g$ 集中在某模式即可 | **模式-seeking**（易崩溃） |

VAE 优化前向 KL $\to$ 样本模糊但多样；GAN 优化反向 KL $\to$ 样本清晰但单一。

## 4. Wasserstein GAN（W-GAN）

### 4.1 Wasserstein 距离

**Earth-Mover 距离（Wasserstein-1）**：
$$W_1(p_{\text{data}}, p_g) = \inf_{\gamma \in \Pi(p_{\text{data}}, p_g)} \mathbb{E}_{(x, y) \sim \gamma}[\|x - y\|]$$

**直观**：将 $p_{\text{data}}$ 的土堆搬到 $p_g$ 的最小工程量。

### 4.2 W-GAN vs 原始 GAN

| 原始 GAN | W-GAN |
|---------|-------|
| 判别器输出概率（sigmoid） | **评论家（Critic）输出实数分数** |
| JS 散度 | Wasserstein-1 距离 |
| 判别器需平衡（不能太强） | 评论家可训练至最优 |
| 梯度消失（分布不重叠时） | **梯度始终有意义** |
| 优化 $\min \log(1-D)$ | 优化 $\min -\mathbb{E}_z[f(G(z))]$ |

**Wasserstein 距离的关键优势**：即使真实分布与生成分布无重叠，依然能提供有意义的梯度信号（KL / JS 在无重叠时是常数）。

### 4.3 Lipschitz 约束

W-GAN 要求评论家 $f$ 满足 **K-Lipschitz 连续**：
$$|f(x_1) - f(x_2)| \leq K \|x_1 - x_2\|$$

**实现**：权重裁剪（Weight Clipping），将参数限制在 $[-c, c]$。

**改进（WGAN-GP）**：用**梯度惩罚**（Gradient Penalty）替代权重裁剪，更平滑且稳定。

## 5. 扩散模型（Diffusion Model）（★★☆ 作业4-2(4)）

### 5.1 核心思想

**正向过程（加噪）**：逐步向数据添加高斯噪声，$T$ 步后数据变为纯噪声。

**反向过程（去噪）**：学习逐步去噪，从纯噪声恢复数据。

### 5.2 正向过程（Fixed）

给定真实数据 $x_0$，每步添加噪声 $q(x_t | x_{t-1})$：
$$q(x_t | x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t} x_{t-1}, \beta_t I)$$

任意 $t$ 步可直接采样：
$$x_t = \sqrt{\bar{\alpha}_t} x_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$
其中 $\alpha_t = 1 - \beta_t$, $\bar{\alpha}_t = \prod_{s=1}^t \alpha_s$。

### 5.3 反向过程（Learned）

学习去噪网络 $p_\theta(x_{t-1} | x_t)$：
$$p_\theta(x_{t-1} | x_t) = \mathcal{N}(x_{t-1}; \mu_\theta(x_t, t), \sigma_t^2 I)$$

### 5.4 损失函数

$$\boxed{\mathcal{L}_{\text{DM}} = \mathbb{E}_{t, x_0, \epsilon} \left[ \|\epsilon - \epsilon_\theta(x_t, t)\|^2 \right]}$$

模型 $\epsilon_\theta$ 预测加在 $x_t$ 上的噪声 $\epsilon$，而非直接预测 $x_0$。

### 5.5 扩散模型 vs 其他生成模型

| 维度 | VAE | GAN | 扩散模型 |
|------|-----|-----|---------|
| 密度估计 | 显式（ELBO） | 隐式 | 显式（ELBO 变体） |
| 训练稳定性 | 稳定 | 不稳定 | **稳定** |
| 样本质量 | 模糊 | 清晰 | **最清晰（SOTA）** |
| 采样速度 | 快（单步） | 快（单步） | **慢（~1000 步）** |
| 模式覆盖 | 好 | 差（易崩溃） | **好** |

**应用**：Stable Diffusion（文生图）、DALL-E、Sora（文生视频）

## 6. 关键公式速查

| 公式 | 含义 |
|------|------|
| $D^*(x) = \frac{p_{\text{data}}(x)}{p_{\text{data}}(x) + p_g(x)}$ | GAN 最优判别器 |
| $\min_G \max_D \mathbb{E}[\log D(x)] + \mathbb{E}[\log(1 - D(G(z)))]$ | GAN Minimax 目标函数 |
| $\mathcal{L}_{\text{VAE}} = -\mathbb{E}_{q}[\log p(x\|z)] + \text{KL}(q(z\|x) \| p(z))$ | VAE 损失函数 |
| $z = \mu + \sigma \odot \epsilon$ | 重参数化技巧 |
| $W_1(p_{\text{data}}, p_g) = \inf_\gamma \mathbb{E}_{(x,y)\sim\gamma}[\|x-y\|]$ | Wasserstein-1 距离 |
| $\mathcal{L}_{\text{DM}} = \mathbb{E}_{t, x_0, \epsilon}[\|\epsilon - \epsilon_\theta(x_t, t)\|^2]$ | 扩散模型损失函数（预测噪声） |
| $x_t = \sqrt{\bar{\alpha}_t} x_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon$ | 扩散模型正向过程 |

## 关键结论

1. **判别 vs 生成**：判别模型学 $p(y|x)$（分类边界），生成模型学 $p(x)$（数据分布）
2. **VAE 核心**：ELBO + 重参数化，使隐变量模型的变分训练可微
3. **GAN 核心**：Minimax 博弈，最优判别器 $D^* = p_{\text{data}} / (p_{\text{data}} + p_g)$
4. **模式崩溃根源**：反向 KL $\text{KL}(p_g\|p_{\text{data}})$ 倾向于拟合单一模式
5. **W-GAN 突破**：Wasserstein 距离在分布不重叠时仍有连续梯度
6. **扩散模型**：正向固定加噪 + 反向学去噪，损失函数为预测噪声的 MSE，当前 SOTA

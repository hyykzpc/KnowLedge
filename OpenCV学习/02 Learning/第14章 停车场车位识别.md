# 第14章：项目实战-停车场车位识别

> **对应视频**: P61-P68 | **时长**: 约70分钟 | **难度**: ★★★★

## 一、核心摘要

> 用传统图像处理方法识别停车场空闲车位。核心思路：检测车位线 → 按列划分区域 → 用 CNN 分类每个车位状态 → 视频实时检测。

## 二、项目 Pipeline

```
输入: 停车场俯拍图像/视频
    ↓
┌─────────────────────────────────────┐
│ 1. 图像预处理                        │
│    灰度 → 高斯滤波 → Canny → 闭运算   │
├─────────────────────────────────────┤
│ 2. 车位线检测                        │
│    HoughLinesP → 筛选水平和垂直线     │
│    → 按位置分组 → 确定车位位置        │
├─────────────────────────────────────┤
│ 3. 车位区域划分                      │
│    按列划分 → 每个车位坐标记录         │
├─────────────────────────────────────┤
│ 4. 识别模型                          │
│    训练 CNN 分类: 空车位 vs 有车       │
│    → 对每个车位区域预测                │
├─────────────────────────────────────┤
│ 5. 视频实时检测                      │
│    逐帧读取 → 预处理 → 预测 → 标注     │
└─────────────────────────────────────┘
    ↓
输出: 标记空闲/占用车位的实时画面
```

## 三、核心步骤详解

### 3.1 车位线检测

**霍夫直线检测（HoughLinesP）**：检测图像中的直线。

```python
lines = cv2.HoughLinesP(edges, rho=1, theta=np.pi/180, threshold=15,
                        minLineLength=40, maxLineGap=20)
```

| 参数 | 含义 | 典型值 |
|------|------|--------|
| rho | 距离精度（像素） | 1 |
| theta | 角度精度（弧度） | π/180 |
| threshold | 最小投票数 | 15 |
| minLineLength | 最小线段长度 | 40 |
| maxLineGap | 线段间最大间隙 | 20 |

### 3.2 按列划分区域

根据检测到的直线位置，将车位按列分组：

```python
# 1. 收集所有 x 坐标，按列聚类
# 2. 每列内按 y 坐标排序，得到每个车位
# 3. 记录每个车位的 (x, y, w, h)
```

### 3.3 CNN 车位状态分类

训练一个简单的 CNN，输入车位区域，输出 "空" 或 "有车"。

```
模型结构:
Conv2D(32, 3×3) → MaxPool → Conv2D(64, 3×3) → MaxPool
→ Flatten → Dense(128) → Dense(2, softmax)
```

### 3.4 原理深入：霍夫变换

霍夫变换的核心思想：**参数空间投票**。

在图像空间中，过点 (x₀, y₀) 的直线有无数条，每一条对应参数空间 (ρ, θ) 中的一个点。所有图像空间中的共线点在参数空间中会交于同一点（投票峰值）。

```
图像空间:                    参数空间:
  y = kx + b                   ρ = x·cosθ + y·sinθ

  点 A → 无数条直线            点 A → 一条正弦曲线
  点 B → 无数条直线            点 B → 一条正弦曲线
  A, B 共线 → 一条确定的直线     两条正弦曲线交于一点 → 投票峰值！
```

## 四、核心 API

| API | 函数签名 | 功能 | 本章用法 |
|-----|----------|------|----------|
| `cv2.HoughLinesP()` | `HoughLinesP(img, rho, theta, threshold, minLineLength, maxLineGap)` | 概率霍夫直线检测 | 检测车位线 |
| `cv2.Canny()` | `Canny(img, t1, t2)` | 边缘检测 | 霍夫变换的前置步骤 |

## 五、代码实战

### 5.1 车位线检测

```python
import cv2
import numpy as np

img = cv2.imread("parking_lot.jpg")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# 预处理
blurred = cv2.GaussianBlur(gray, (5, 5), 0)
edges = cv2.Canny(blurred, 50, 150)
edges = cv2.morphologyEx(edges, cv2.MORPH_CLOSE, np.ones((3, 3), np.uint8))

# 霍夫直线检测
lines = cv2.HoughLinesP(edges, rho=1, theta=np.pi/180, threshold=15,
                        minLineLength=40, maxLineGap=20)

# 筛选水平和垂直线
horiz_lines = []
vert_lines = []
if lines is not None:
    for line in lines:
        x1, y1, x2, y2 = line[0]
        angle = np.abs(np.arctan2(y2 - y1, x2 - x1) * 180 / np.pi)
        if angle < 10 or angle > 170:
            horiz_lines.append(line[0])
        elif 80 < angle < 100:
            vert_lines.append(line[0])

# 绘制检测到的直线
for line in horiz_lines + vert_lines:
    x1, y1, x2, y2 = line
    cv2.line(img, (x1, y1), (x2, y2), (0, 255, 0), 2)

cv2.imshow("Detected Lines", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 5.2 效果对比

| 步骤 | 效果 |
|------|------|
| Canny 边缘检测 | 提取车位线边缘 |
| 闭运算 | 连接断裂的边缘线 |
| HoughLinesP | 检测出所有直线 |
| 角度筛选 | 分离水平和垂直线 |
| 按列分组 | 确定每个车位位置 |

## 六、调试经验与避坑指南

| 问题现象 | 原因 | 解决方案 |
|----------|------|----------|
| 检测不到直线 | Canny 阈值太高或太低 | 调整 Canny 阈值 |
| 检测到太多杂线 | HoughLinesP 阈值太低 | 提高 threshold |
| 直线断断续续 | 边缘不连续 | 用闭运算连接，或增大 maxLineGap |
| 车位划分不准 | 直线方向不纯 | 用角度筛选过滤斜线 |

### 常见坑点
- **坑点1**: HoughLinesP 返回的是线段端点，不是直线方程
- **坑点2**: 角度筛选时注意角度范围：水平线 angle≈0° 或 180°，垂直线 angle≈90°
- **坑点3**: 视频检测时需缓存车位坐标，避免每帧重复检测

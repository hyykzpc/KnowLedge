# 第16章：背景建模

> **对应视频**: P73-P76 | **时长**: 约28分钟 | **难度**: ★★★

## 一、核心摘要

> 背景建模是从视频中分离前景（运动物体）的技术。帧差法最简单但效果差，混合高斯模型（MOG2）用多个高斯分布建模每个像素，能自适应光照变化和动态背景，是实际项目中的首选。

## 二、知识图谱

```
背景建模
├── 帧差法
│   └── 当前帧 - 上一帧 → 变化区域 = 前景
│       ├── 优点: 简单快速
│       └── 缺点: 空洞、鬼影、对光照敏感
│
├── 混合高斯模型 (MOG/MOG2)
│   ├── 每个像素用 K 个高斯分布建模
│   ├── 在线学习更新参数
│   ├── 自适应光照变化
│   └── 能处理动态背景（如摇曳的树叶）
│
└── 应用场景
    ├── 运动目标检测
    ├── 行人/车辆计数
    └── 异常行为检测
```

## 三、核心概念

### 3.1 帧差法

**原理**：

$$D_t(x,y) = |I_t(x,y) - I_{t-1}(x,y)|$$

$D_t > 阈值$ 的像素 = 前景（运动物体）。

**为什么有"鬼影"？**

```
帧 t-1:  ██████░░░░░░    物体在位置 A
帧 t:    ░░░░░░██████    物体移动到位置 B

差值:     ████████████    位置 A 和 B 都被检测为变化
         鬼影    真实
→ 位置 A 的"变化"其实是物体离开后的背景，不是真正的运动
```

**改进方案**：三帧差法（取连续两帧差分的交集），可以减少鬼影。

### 3.2 混合高斯模型（MOG2）

**核心思想**：每个像素不是固定的颜色值，而是多个高斯分布的混合。

```
像素变化的建模:
  背景像素: 在几个值之间小幅波动（如树叶摇曳）
  前景像素: 突然出现一个不在任何高斯分布中的值

MOG2 的决策:
  新像素值 → 和 K 个高斯分布逐一比较
    → 如果匹配某个分布 → 该像素是背景
    → 如果不匹配任何分布 → 该像素是前景！
```

**关键参数**：

| 参数 | 含义 | 默认值 |
|------|------|--------|
| history | 用于建模的帧数 | 500 |
| varThreshold | 方差阈值 | 16 |
| detectShadows | 是否检测阴影 | True |

### 3.3 原理深入：MOG2 的在线学习

MOG2 不是离线的——它不断更新：

```
对每一帧:
1. 将每个像素值与 K 个高斯分布比较
2. 如果匹配 → 更新该高斯分布的均值和方差
3. 如果不匹配 → 替换最不可能的高斯分布
4. 按权重排序，前 B 个分布为背景，其余为前景
```

**为什么能自适应？** 因为参数在持续更新。光照渐变、树叶摇曳等变化会逐渐被"学"进背景模型中。

### 3.4 原理深入：MOG vs MOG2 vs KNN

| 算法 | 特点 | 适用场景 |
|------|------|----------|
| MOG (cv2.bgsegm.createBackgroundSubtractorMOG) | 原始混合高斯模型 | 基础场景 |
| **MOG2** (cv2.createBackgroundSubtractorMOG2) | 自适应选择 K 值，阴影检测 | **推荐，通用场景** |
| KNN (cv2.createBackgroundSubtractorKNN) | K 近邻建模，对动态背景更好 | 复杂动态背景 |

## 四、核心 API

| API | 函数签名 | 功能 | 关键参数 |
|-----|----------|------|----------|
| `cv2.createBackgroundSubtractorMOG2()` | `createBackgroundSubtractorMOG2([history, varThreshold, detectShadows])` | 创建 MOG2 背景减除器 | history=500, detectShadows=True |
| `mog2.apply()` | `apply(image[, learningRate])` | 对一帧应用背景减除 | learningRate=-1（自动） |

## 五、代码实战

### 5.1 帧差法

```python
import cv2

cap = cv2.VideoCapture("video.mp4")

ret, prev_frame = cap.read()
prev_gray = cv2.cvtColor(prev_frame, cv2.COLOR_BGR2GRAY)

while True:
    ret, frame = cap.read()
    if not ret:
        break

    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    diff = cv2.absdiff(gray, prev_gray)

    _, fg_mask = cv2.threshold(diff, 30, 255, cv2.THRESH_BINARY)

    cv2.imshow("Frame Difference", fg_mask)
    prev_gray = gray

    if cv2.waitKey(30) & 0xFF == 27:
        break

cap.release()
cv2.destroyAllWindows()
```

### 5.2 MOG2 背景建模

```python
import cv2

cap = cv2.VideoCapture("video.mp4")
mog2 = cv2.createBackgroundSubtractorMOG2(history=500, varThreshold=16, detectShadows=True)

while True:
    ret, frame = cap.read()
    if not ret:
        break

    # 应用背景减除
    fg_mask = mog2.apply(frame)

    # 形态学后处理：去噪 + 填孔
    kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3))
    fg_mask = cv2.morphologyEx(fg_mask, cv2.MORPH_OPEN, kernel)   # 去小白点
    fg_mask = cv2.morphologyEx(fg_mask, cv2.MORPH_CLOSE, kernel)  # 填小黑洞

    # 提取前景区域
    fg = cv2.bitwise_and(frame, frame, mask=fg_mask)

    cv2.imshow("Foreground Mask", fg_mask)
    cv2.imshow("Foreground", fg)

    if cv2.waitKey(30) & 0xFF == 27:
        break

cap.release()
cv2.destroyAllWindows()
```

### 5.3 效果对比

| 方法 | 效果 | 适用场景 |
|------|------|----------|
| 帧差法 | 有鬼影和空洞，噪声多 | 静态背景、快速原型 |
| MOG2 | 前景完整，自适应光照 | 通用运动检测 |
| MOG2 + 形态学处理 | 前景干净，噪声少 | 正式项目 |

## 六、调试经验与避坑指南

| 问题现象 | 原因 | 解决方案 |
|----------|------|----------|
| 前景掩膜全是噪点 | varThreshold 太低 | 提高 varThreshold 到 25-50 |
| 运动物体检测不到 | varThreshold 太高 | 降低 varThreshold |
| 鬼影残留 | 物体移动太快 | 增大 history |
| 阴影被检测为前景 | detectShadows=False | 设 detectShadows=True |

### 常见坑点
- **坑点1**: MOG2 的 history 参数是帧数，不是秒数 → 30fps 的视频，500 帧 ≈ 17 秒
- **坑点2**: 背景减除后必须做形态学后处理 → 否则噪声太多
- **坑点3**: learningRate 默认 -1 表示自动 → 通常不需要手动设置

## 七、本章小结

- **必掌握**: 帧差法原理、MOG2 的使用、形态学后处理

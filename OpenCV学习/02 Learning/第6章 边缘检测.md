# 第6章：边缘检测

> **对应视频**: P19-P21 | **时长**: 约19分钟 | **难度**: ★★★

## 一、核心摘要

> Canny 边缘检测是计算机视觉中最经典的边缘检测算法，它通过五步流程（高斯滤波→梯度→NMS→双阈值→边缘连接），从噪声图像中提取出干净、连续的边缘。

- Canny 不是简单的梯度阈值，而是一套完整的边缘检测 pipeline
- 非极大值抑制（NMS）是 Canny 的精髓，它让边缘从粗变细
- 双阈值解决了"弱边缘要不要保留"的问题

## 二、知识图谱

```
Canny 边缘检测五步流程:
┌────────────────────────────────────────────────┐
│ 1. 高斯滤波 → 去噪                              │
│    ↓                                           │
│ 2. Sobel 梯度 → 计算幅值和方向                  │
│    ↓                                           │
│ 3. 非极大值抑制(NMS) → 细化边缘（Canny的精髓）  │
│    ↓                                           │
│ 4. 双阈值检测 → 强边缘/弱边缘/非边缘             │
│    ↓                                           │
│ 5. 边缘连接 → 弱边缘若与强边缘相邻则保留         │
└────────────────────────────────────────────────┘
```

## 三、核心概念

### 3.1 Canny 边缘检测流程

**第一步：高斯滤波**

- 平滑图像，去除噪声
- 核大小通常用 5×5

**第二步：计算梯度**

- 用 Sobel 算子计算 Gx 和 Gy
- 幅值: $G = \sqrt{Gx^2 + Gy^2}$
- 方向: $\theta = \arctan(Gy / Gx)$

**第三步：非极大值抑制（NMS）**

- 沿梯度方向，只保留局部最大值
- 其他像素抑制为 0
- 效果: 边缘从粗变细，从模糊变清晰

**第四步：双阈值检测**

| 阈值 | 作用 |
|------|------|
| 高于 maxVal | 强边缘，直接保留 |
| 介于 minVal 和 maxVal | 弱边缘，待定 |
| 低于 minVal | 非边缘，丢弃 |

**第五步：边缘连接**

- 弱边缘如果与强边缘相邻（8邻域），则保留
- 否则丢弃

### 3.2 原理深入：NMS 为什么是 Canny 的精髓

**没有 NMS 的问题**：梯度在边缘附近会有多个像素响应，导致边缘粗大模糊。

```
没有 NMS 的梯度:              有 NMS 的梯度:
    ████████                       ████
    ████████                       ████
    ████████     → 边缘很粗          ████     → 边缘很细
    ████████                       ████
    ████████                       ████
```

**NMS 的工作方式**：

1. 将梯度方向离散化为 4 个方向：0°, 45°, 90°, 135°
2. 沿梯度方向，比较当前像素和相邻两个像素
3. 如果当前像素不是最大 → 抑制为 0

```
梯度方向 → 90°（垂直向上）:
  像素A
  像素B ← 当前位置
  像素C

  if B > A and B > C: 保留 B
  else: B = 0
```

### 3.3 原理深入：双阈值的参数调优

**双阈值是 Canny 最关键的两个参数**：

| 参数 | 典型范围 | 影响 |
|------|----------|------|
| minVal | 50~100 | 越低 → 检出更多弱边缘 → 可能引入噪声 |
| maxVal | 100~200 | 越高 → 强边缘要求越严格 → 可能丢失真实边缘 |

**经验法则**：`maxVal : minVal ≈ 3:1 或 2:1`

```
minVal=50,  maxVal=150:  边缘较多，可能有噪声
minVal=100, maxVal=200:  边缘适中
minVal=150, maxVal=300:  边缘较少，更保守
```

**自动调参技巧**：如果图像噪声大，提高 minVal；如果边缘丢失多，降低 maxVal。

### 3.4 原理深入：Canny 与其他边缘检测方法的对比

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| Sobel | 一阶梯度阈值 | 简单快速 | 边缘粗，噪声多 |
| Laplacian | 二阶过零点 | 边缘定位精确 | 对噪声极其敏感 |
| **Canny** | 梯度+NMS+双阈值 | **边缘细、连续、抗噪** | 参数需调优 |
| 形态学梯度 | 膨胀-腐蚀 | 实现简单 | 边缘粗，不适合精细检测 |

## 四、核心 API

| API | 函数签名 | 功能 | 关键参数 |
|-----|----------|------|----------|
| `cv2.Canny()` | `Canny(image, threshold1, threshold2[, edges, apertureSize, L2gradient])` | Canny 边缘检测 | threshold1=minVal, threshold2=maxVal |

> `apertureSize` 是 Sobel 核大小，默认 3；`L2gradient=True` 用精确的 sqrt(Gx²+Gy²)，False 用 |Gx|+|Gy| 近似。

## 五、代码实战

### 5.1 基础 Canny 边缘检测

```python
import cv2
import numpy as np

img = cv2.imread("lena.jpg", cv2.IMREAD_GRAYSCALE)

# Canny 边缘检测
edges = cv2.Canny(img, threshold1=100, threshold2=200)

# 对比：直接 Sobel 二值化
sobel_x = cv2.Sobel(img, cv2.CV_64F, 1, 0, ksize=3)
sobel_y = cv2.Sobel(img, cv2.CV_64F, 0, 1, ksize=3)
sobel_abs = cv2.convertScaleAbs(sobel_x) + cv2.convertScaleAbs(sobel_y)

res = np.hstack((img, sobel_abs, edges))
cv2.imshow("Original | Sobel | Canny", res)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 5.2 不同阈值对比

```python
# 对比不同阈值的效果
edges_low  = cv2.Canny(img, 50, 150)    # 低阈值：边缘多
edges_mid  = cv2.Canny(img, 100, 200)   # 中阈值：适中
edges_high = cv2.Canny(img, 150, 250)   # 高阈值：边缘少

res = np.hstack((edges_low, edges_mid, edges_high))
cv2.imshow("Low | Mid | High", res)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 5.3 先滤波再 Canny

```python
# 先高斯滤波去噪，再 Canny
blurred = cv2.GaussianBlur(img, (5, 5), sigmaX=1)
edges_clean = cv2.Canny(blurred, 50, 150)

# 不滤波直接 Canny（噪声多的场景）
edges_noisy = cv2.Canny(img, 50, 150)

res = np.hstack((edges_noisy, edges_clean))
cv2.imshow("No filter | With Gaussian filter", res)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 5.4 效果对比

| 参数设置 | 效果描述 | 适用场景 |
|----------|----------|----------|
| Canny(50, 150) | 边缘丰富，可能有噪声 | 干净图像，需要更多细节 |
| Canny(100, 200) | 边缘适中，噪声少 | 通用场景 |
| Canny(150, 250) | 仅保留强边缘 | 目标轮廓提取 |
| 先高斯滤波 + Canny | 边缘更干净 | 噪声较多的图像 |

## 六、调试经验与避坑指南

| 问题现象 | 原因 | 解决方案 |
|----------|------|----------|
| 边缘太多，全是噪点 | minVal 太低 | 提高 minVal 到 100+ |
| 边缘太少，重要轮廓丢失 | maxVal 太高 | 降低 maxVal 到 150 左右 |
| 边缘不连续，断断续续 | 图像噪声大 | 先做高斯滤波 |
| 边缘太粗 | 没有 NMS？ | Canny 自带 NMS，检查参数是否正确 |

### 常见坑点
- **坑点1**: 混淆 threshold1 和 threshold2 → threshold1 是 minVal（弱边缘阈值），threshold2 是 maxVal（强边缘阈值）
- **坑点2**: 以为 Canny 内部会自动去噪 → 内部只有一次高斯滤波（5×5），噪声大时需额外滤波
- **坑点3**: 用彩色图直接 Canny → 需要先转灰度

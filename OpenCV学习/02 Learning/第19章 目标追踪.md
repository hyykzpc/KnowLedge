# 第19章：项目实战-目标追踪

> **对应视频**: P80-P85（目标追踪部分） | **时长**: 约50分钟 | **难度**: ★★★★

## 一、核心摘要

> 目标追踪是在视频序列中持续定位目标位置。OpenCV 提供了多种追踪器（KCF、CSRT、MIL 等），以及结合深度学习检测器（SSD、YOLO）的多目标追踪方案。多进程/多线程可以大幅提升追踪效率。

## 二、知识图谱

```
目标追踪
├── 单目标追踪
│   ├── KCF（核相关滤波）→ 速度快
│   ├── CSRT（判别式相关滤波）→ 精度高但慢
│   ├── MIL（多实例学习）→ 抗遮挡
│   └── MOSSE → 极快但精度低
│
├── 多目标追踪
│   ├── 检测 + 追踪 结合
│   │   ├── 深度学习检测器: SSD / YOLO
│   │   └── 追踪器: KCF / CSRT
│   └── 多进程并行 → 提升效率
│
└── 追踪器选择指南
    ├── 追求速度: KCF
    ├── 追求精度: CSRT
    ├── 抗遮挡: MIL
    └── 极速: MOSSE
```

## 三、核心概念

### 3.1 追踪器对比

| 追踪器 | 速度 | 精度 | 抗遮挡 | 适用场景 |
|--------|------|------|--------|----------|
| KCF | 快 | 中 | 一般 | 实时追踪首选 |
| CSRT | 慢 | 高 | 较好 | 精度要求高 |
| MIL | 中 | 中 | 较好 | 部分遮挡场景 |
| MOSSE | 极快 | 低 | 差 | 资源受限 |

### 3.2 检测 + 追踪框架

**为什么需要检测器？** 追踪器需要手动初始化（框选目标），无法自动发现新目标。

**检测 + 追踪方案**：

```
视频帧
    ↓
检测器(SSD/YOLO) → 发现目标
    ↓
追踪器(KCF/CSRT) → 持续跟踪
    ↓
目标丢失？ → 重新检测
```

### 3.3 多进程加速

**问题**：多目标追踪，串行处理每个追踪器很慢。

**解决**：用 `multiprocessing` 将每个追踪器放到独立进程。

```python
from multiprocessing import Process, Queue

# 每个目标一个进程，独立追踪
for tracker in trackers:
    p = Process(target=track_object, args=(tracker, frame_queue, result_queue))
    p.start()
```

### 3.4 原理深入：KCF 核心思想

KCF（Kernelized Correlation Filter）的核心：

1. 在第一帧目标位置采样正负样本
2. 训练一个**相关滤波器**（使正样本响应高，负样本响应低）
3. 后续帧中，新位置与滤波器做相关运算，响应最大值 = 目标位置
4. 在线更新滤波器（适应外观变化）

**为什么快？** 相关运算在频域变成了点乘，FFT 加速。

### 3.5 原理深入：dlib + SSD 方案

课程中使用了 dlib 的 `correlation_tracker` 结合 SSD 检测器：

```python
# dlib 追踪器
import dlib
tracker = dlib.correlation_tracker()
tracker.start_track(frame, dlib.rectangle(x1, y1, x2, y2))

# 后续帧更新
tracker.update(frame)
pos = tracker.get_position()  # 获取新位置
```

## 四、核心 API

| API | 函数签名 | 功能 |
|-----|----------|------|
| `cv2.TrackerKCF_create()` | `TrackerKCF_create()` | 创建 KCF 追踪器 |
| `cv2.TrackerCSRT_create()` | `TrackerCSRT_create()` | 创建 CSRT 追踪器 |
| `tracker.init()` | `init(frame, bbox)` | 初始化追踪器 |
| `tracker.update()` | `update(frame)` | 更新追踪（返回 success, bbox） |

## 五、代码实战

### 5.1 单目标追踪

```python
import cv2

cap = cv2.VideoCapture("video.mp4")

# 读取第一帧，手动选择目标
ret, frame = cap.read()
bbox = cv2.selectROI("Select Target", frame, False)
cv2.destroyWindow("Select Target")

# 创建追踪器
tracker = cv2.TrackerKCF_create()
tracker.init(frame, bbox)

while True:
    ret, frame = cap.read()
    if not ret:
        break

    success, bbox = tracker.update(frame)
    if success:
        x, y, w, h = [int(v) for v in bbox]
        cv2.rectangle(frame, (x, y), (x + w, y + h), (0, 255, 0), 2)
    else:
        cv2.putText(frame, "Lost", (50, 50), cv2.FONT_HERSHEY_SIMPLEX, 1, (0,0,255), 2)

    cv2.imshow("Tracking", frame)
    if cv2.waitKey(30) & 0xFF == 27:
        break

cap.release()
cv2.destroyAllWindows()
```

### 5.2 多追踪器对比

```python
# 创建多个追踪器对比效果
trackers = {
    "KCF": cv2.TrackerKCF_create(),
    "CSRT": cv2.TrackerCSRT_create(),
    # "MIL": cv2.TrackerMIL_create(),  # 如果支持
}

for name, tracker in trackers.items():
    tracker.init(frame, bbox)

# 每帧更新所有追踪器，用不同颜色显示
colors = {"KCF": (0, 255, 0), "CSRT": (255, 0, 0)}
for name, tracker in trackers.items():
    success, bbox = tracker.update(frame)
    if success:
        x, y, w, h = [int(v) for v in bbox]
        cv2.rectangle(frame, (x, y), (x+w, y+h), colors[name], 2)
        cv2.putText(frame, name, (x, y-5), cv2.FONT_HERSHEY_SIMPLEX, 0.5, colors[name], 2)
```

### 5.3 效果对比

| 追踪器 | 效果 | 适用场景 |
|--------|------|----------|
| KCF | 快速跟踪，偶尔漂移 | 实时场景 |
| CSRT | 精确跟踪，但帧率低 | 离线分析 |
| 检测 + KCF | 自动发现目标 + 持续跟踪 | 多目标场景 |

## 六、调试经验与避坑指南

| 问题现象 | 原因 | 解决方案 |
|----------|------|----------|
| 追踪器初始化失败 | bbox 格式错误 | 确认 bbox 为 (x, y, w, h) |
| 追踪漂移 | 目标外观变化大 | 换 CSRT 或重新初始化 |
| 目标丢失后不恢复 | 追踪器没有检测能力 | 定期用检测器重新初始化 |
| 多目标追踪卡顿 | 串行处理慢 | 用多进程并行 |

### 常见坑点
- **坑点1**: `cv2.selectROI` 返回的 bbox 已经是 (x, y, w, h) 格式
- **坑点2**: 不同 OpenCV 版本追踪器 API 不同 → 检查 `cv2.TrackerXXX_create` 是否可用
- **坑点3**: 追踪器丢目标后不会自动恢复 → 需要外部检测逻辑

## 七、本章小结

- **必掌握**: 追踪器初始化 + update 循环、KCF vs CSRT 的选择
- **选了解**: 多进程并行、dlib 追踪器
- **一句话总结**: 追踪器持续跟踪已知目标，检测器发现新目标，两者结合才是完整的多目标追踪方案

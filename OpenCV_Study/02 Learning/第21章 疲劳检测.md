# 第21章：项目实战-疲劳检测

> **对应视频**: P94-P98（疲劳检测部分） | **时长**: 约30分钟 | **难度**: ★★★★

## 一、核心摘要

> 用 dlib 或 MediaPipe 检测人脸关键点（landmarks），通过眼睛关键点的 EAR（Eye Aspect Ratio）指标判断是否闭眼，连续闭眼超过阈值则判定为疲劳。这是计算机视觉在安全领域的经典应用。

## 二、项目 Pipeline

```
输入: 摄像头实时视频
    ↓
┌─────────────────────────────────────┐
│ 1. 人脸检测                          │
│    dlib 正面人脸检测器 / Haar 级联    │
├─────────────────────────────────────┤
│ 2. 关键点定位                        │
│    dlib 68 关键点 / MediaPipe 468点  │
│    → 提取眼睛周围关键点               │
├─────────────────────────────────────┤
│ 3. EAR 计算                          │
│    EAR = (|P2-P6|+|P3-P5|) / (2|P1-P4|) │
│    → EAR 持续低于阈值 = 闭眼          │
├─────────────────────────────────────┤
│ 4. 疲劳判定                          │
│    连续闭眼帧数 > 阈值 → 疲劳告警     │
└─────────────────────────────────────┘
    ↓
输出: 视频画面 + 疲劳告警
```

## 三、核心概念

### 3.1 人脸关键点

**68 个关键点分布**：

```
眉毛: 18-22, 23-27
眼睛: 37-42（左眼）, 43-48（右眼）
鼻子: 28-36
嘴巴: 49-68
下巴: 1-17
```

**眼睛关键点（以左眼为例）**：

```
     P1
    /  \          P1=37, P2=38, P3=39
  P2    P3        P4=40, P5=41, P6=42
  |      |
  P4    P5
    \  /
     P6
```

### 3.2 EAR（Eye Aspect Ratio）

**公式**：

$$\text{EAR} = \frac{|P_2 - P_6| + |P_3 - P_5|}{2 \cdot |P_1 - P_4|}$$

**直观理解**：

- 睁眼：分母（眼睛宽度）基本不变，分子（眼睛高度）大 → EAR 大（约 0.3+）
- 闭眼：分子（眼睛高度）接近 0 → EAR 接近 0（约 < 0.2）

```python
def eye_aspect_ratio(eye):
    # 计算两组垂直距离
    A = np.linalg.norm(eye[1] - eye[5])  # P2-P6
    B = np.linalg.norm(eye[2] - eye[4])  # P3-P5
    # 计算水平距离
    C = np.linalg.norm(eye[0] - eye[3])  # P1-P4
    # EAR
    ear = (A + B) / (2.0 * C)
    return ear
```

### 3.3 疲劳判定逻辑

```python
EYE_AR_THRESH = 0.25       # EAR 低于此值 → 闭眼
EYE_AR_CONSEC_FRAMES = 20  # 连续闭眼 20 帧 → 疲劳告警

if ear < EYE_AR_THRESH:
    counter += 1
else:
    if counter >= EYE_AR_CONSEC_FRAMES:
        alarm = True  # 疲劳告警
    counter = 0
```

### 3.4 原理深入：为什么 EAR 能检测疲劳？

**正常眨眼**：快速闭眼 → 立即睁眼（3-5 帧），EAR 短暂下降。

**疲劳**：闭眼时间延长（20+ 帧），EAR 持续低于阈值。

```
EAR 曲线:
    正常眨眼:           疲劳:
    ┌─┐                  ┌───────┐
    │ │                  │       │
────┘ └─────         ────┘       └────
  3-5帧                  20+帧
→ 不告警                  → 告警！
```

### 3.5 原理深入：dlib vs MediaPipe

| 特性 | dlib | MediaPipe |
|------|------|-----------|
| 关键点数 | 68 | 468 |
| 安装 | 较重（需编译） | 轻量（pip install） |
| 速度 | 中 | 快 |
| 精度 | 高 | 高 |
| 推荐 | 精确场景 | 实时场景 |

## 四、核心 API

| API | 函数签名 | 功能 |
|-----|----------|------|
| `dlib.get_frontal_face_detector()` | 创建人脸检测器 | 检测人脸位置 |
| `dlib.shape_predictor()` | 加载 68 关键点模型 | 预测关键点 |
| `detector(frame, 1)` | 检测人脸 | 返回人脸矩形列表 |
| `predictor(gray, rect)` | 预测关键点 | 返回 68 个关键点 |

## 五、代码实战

### 5.1 完整疲劳检测

```python
import cv2
import dlib
import numpy as np
from scipy.spatial import distance as dist

def eye_aspect_ratio(eye):
    A = dist.euclidean(eye[1], eye[5])
    B = dist.euclidean(eye[2], eye[4])
    C = dist.euclidean(eye[0], eye[3])
    return (A + B) / (2.0 * C)

# 加载模型
detector = dlib.get_frontal_face_detector()
predictor = dlib.shape_predictor("shape_predictor_68_face_landmarks.dat")

# 左右眼关键点索引
(lStart, lEnd) = (42, 48)  # 左眼
(rStart, rEnd) = (36, 42)  # 右眼

EYE_AR_THRESH = 0.25
EYE_AR_CONSEC_FRAMES = 20
counter = 0
alarm = False

cap = cv2.VideoCapture(0)

while True:
    ret, frame = cap.read()
    if not ret:
        break

    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    faces = detector(gray, 0)

    for face in faces:
        shape = predictor(gray, face)
        shape = np.array([[p.x, p.y] for p in shape.parts()])

        # 提取左右眼关键点
        left_eye = shape[lStart:lEnd]
        right_eye = shape[rStart:rEnd]

        # 计算 EAR
        left_ear = eye_aspect_ratio(left_eye)
        right_ear = eye_aspect_ratio(right_eye)
        ear = (left_ear + right_ear) / 2.0

        # 绘制眼睛轮廓
        cv2.polylines(frame, [cv2.convexHull(left_eye)], True, (0, 255, 0), 1)
        cv2.polylines(frame, [cv2.convexHull(right_eye)], True, (0, 255, 0), 1)

        # 疲劳判定
        if ear < EYE_AR_THRESH:
            counter += 1
            if counter >= EYE_AR_CONSEC_FRAMES:
                cv2.putText(frame, "DROWSINESS ALERT!", (10, 30),
                            cv2.FONT_HERSHEY_SIMPLEX, 0.7, (0, 0, 255), 2)
        else:
            counter = 0

        # 显示 EAR
        cv2.putText(frame, f"EAR: {ear:.2f}", (300, 30),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.7, (0, 255, 0), 2)

    cv2.imshow("Fatigue Detection", frame)
    if cv2.waitKey(1) & 0xFF == 27:
        break

cap.release()
cv2.destroyAllWindows()
```

### 5.2 效果对比

| 参数 | 效果 |
|------|------|
| EAR_THRESH=0.25 | 标准阈值，大多数人适用 |
| EAR_THRESH=0.20 | 严格模式，仅大眼适用 |
| CONSEC_FRAMES=20 | 约 0.67 秒（30fps） |
| CONSEC_FRAMES=30 | 约 1 秒，减少误报 |

## 六、调试经验与避坑指南

| 问题现象 | 原因 | 解决方案 |
|----------|------|----------|
| 检测不到人脸 | 光照太暗或人脸角度偏 | 调整光线或头部位置 |
| EAR 一直很低 | 眼睛本来就小 | 降低 EYE_AR_THRESH |
| 频繁误报 | 阈值太敏感 | 增大 CONSEC_FRAMES |
| dlib 安装失败 | 缺乏编译环境 | 用 conda 安装或换 MediaPipe |

### 常见坑点
- **坑点1**: 需要下载 `shape_predictor_68_face_landmarks.dat` 文件（约 100MB）
- **坑点2**: 左右眼关键点索引因版本可能不同 → 确认 dlib 版本的关键点顺序
- **坑点3**: 嘴巴张开（打哈欠）也是疲劳特征 → 可以同时检测 MAR（Mouth Aspect Ratio）

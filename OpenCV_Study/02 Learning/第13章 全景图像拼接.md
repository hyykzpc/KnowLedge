# 第13章：案例实战-全景图像拼接

> **对应视频**: P57-P60 | **时长**: 约33分钟 | **难度**: ★★★★

## 一、核心摘要

> 全景图像拼接是将多张有重叠区域的图像合成一张全景图。核心流程：SIFT 特征提取 → KNN 匹配 → Lowe's ratio test → RANSAC 计算单应性矩阵 → 透视变换拼接。

## 二、项目 Pipeline

```
输入: 多张有重叠的图像
    ↓
┌─────────────────────────────────────┐
│ 1. SIFT 特征提取                     │
│    每张图 → 检测关键点 + 描述子       │
├─────────────────────────────────────┤
│ 2. 特征匹配                          │
│    BFMatcher + KNN (k=2)            │
│    + Lowe's ratio test 筛选好匹配     │
├─────────────────────────────────────┤
│ 3. 单应性矩阵计算                     │
│    RANSAC 算法 → 随机采样 → 内点筛选  │
│    → 最优 3×3 单应性矩阵 H            │
├─────────────────────────────────────┤
│ 4. 透视变换 + 拼接                   │
│    将图像 A 变换到图像 B 的坐标系      │
│    → 融合拼接                         │
└─────────────────────────────────────┘
    ↓
输出: 全景拼接图
```

## 三、核心步骤详解

### 3.1 特征匹配策略

**KNN 匹配 (k=2)**：为每个特征点找 2 个最近邻匹配。

**Lowe's ratio test**：如果最近邻距离远小于次近邻，说明这是"唯一"的好匹配；如果两者接近，说明有歧义，应丢弃。

```python
good = []
for m, n in matches:
    if m.distance < 0.75 * n.distance:  # 最近邻显著优于次近邻
        good.append(m)
```

**直觉理解**：如果最近邻距离 100，次近邻距离 200（ratio=0.5），说明匹配很可靠。如果最近邻 100，次近邻 105（ratio≈0.95），说明有歧义。

### 3.2 RANSAC 算法

**全称**: Random Sample Consensus（随机采样一致性）

**核心思想**：从有噪声的匹配点对中，迭代找到能解释最多数据的模型。

```
算法步骤:
1. 随机选 4 对匹配点（计算单应性矩阵最少需要 4 对）
2. 用这 4 对点计算单应性矩阵 H
3. 用 H 检验所有匹配点对，统计内点（误差 < 阈值的点对）
4. 重复步骤 1-3，保留内点最多的 H
5. 用所有内点重新计算最终的 H
```

**为什么需要 RANSAC？** 特征匹配中总会有错误匹配（外点），直接全部使用会得到错误的变换矩阵。RANSAC 能自动排除外点。

### 3.3 单应性矩阵

**什么是单应性矩阵？**

单应性矩阵描述了两个平面之间的映射关系。在图像拼接中，它描述了一张图到另一张图的透视变换：

$$\begin{bmatrix} x' \\ y' \\ 1 \end{bmatrix} \sim H \begin{bmatrix} x \\ y \\ 1 \end{bmatrix}, \quad H = \begin{bmatrix} h_{11} & h_{12} & h_{13} \\ h_{21} & h_{22} & h_{23} \\ h_{31} & h_{32} & h_{33} \end{bmatrix}$$

### 3.4 原理深入：为什么最少 4 对点？

单应性矩阵有 8 个自由度（$h_{33}$ 通常固定为 1），每对点提供 2 个方程，所以需要 4 对点才能解出：

$$\text{4 对点} \times \text{2 个方程/对} = \text{8 个方程} = \text{8 个未知数}$$

**但 RANSAC 为什么常用 4 对？** 4 对是最少需要的数量，用最少点计算模型能最大化找到"干净"内点的概率。

### 3.5 原理深入：Lowe's ratio test 的数学原理

**为什么 ratio < 0.75？**

对于正确匹配，最近邻描述子距离（d₁）远小于次近邻距离（d₂），因为正确的特征点是唯一的。对于错误匹配，d₁ 和 d₂ 差距不大，因为没有真正的对应点。

Lowe 实验表明，ratio=0.75 能过滤掉 90% 的错误匹配，同时只丢失不到 5% 的正确匹配。

## 四、核心 API

| API | 函数签名 | 功能 | 本章用法 |
|-----|----------|------|----------|
| `cv2.BFMatcher()` | `BFMatcher([normType])` | 暴力匹配器 | normType=NORM_L2（SIFT） |
| `bf.knnMatch()` | `knnMatch(des1, des2, k)` | KNN 匹配 | k=2 |
| `cv2.findHomography()` | `findHomography(src, dst, method[, ransacReprojThreshold])` | 计算单应性矩阵 | method=RANSAC |
| `cv2.warpPerspective()` | `warpPerspective(src, H, dsize)` | 透视变换 | 对图像 A 应用 H 变换 |

## 五、代码实战

### 5.1 完整拼接流程

```python
import cv2
import numpy as np

def stitch_images(img1, img2):
    """将 img2 拼接到 img1 上"""
    gray1 = cv2.cvtColor(img1, cv2.COLOR_BGR2GRAY)
    gray2 = cv2.cvtColor(img2, cv2.COLOR_BGR2GRAY)

    # 1. SIFT 特征提取
    sift = cv2.SIFT_create()
    kp1, des1 = sift.detectAndCompute(gray1, None)
    kp2, des2 = sift.detectAndCompute(gray2, None)

    # 2. KNN 匹配 + Lowe's ratio test
    bf = cv2.BFMatcher()
    matches = bf.knnMatch(des1, des2, k=2)
    good = []
    for m, n in matches:
        if m.distance < 0.75 * n.distance:
            good.append(m)

    print(f"好匹配点数: {len(good)}")

    if len(good) < 4:
        print("匹配点不足，无法拼接")
        return None

    # 3. 提取匹配点坐标
    src_pts = np.float32([kp1[m.queryIdx].pt for m in good]).reshape(-1, 1, 2)
    dst_pts = np.float32([kp2[m.trainIdx].pt for m in good]).reshape(-1, 1, 2)

    # 4. RANSAC 计算单应性矩阵
    H, mask = cv2.findHomography(src_pts, dst_pts, cv2.RANSAC, ransacReprojThreshold=5.0)

    print(f"单应性矩阵:\n{H}")

    # 5. 透视变换 + 拼接
    h1, w1 = img1.shape[:2]
    h2, w2 = img2.shape[:2]

    # 将 img1 变换到 img2 的坐标系
    warped = cv2.warpPerspective(img1, H, (w1 + w2, h1))
    warped[0:h2, 0:w2] = img2  # 将 img2 放在左侧

    return warped

# 使用
img1 = cv2.imread("left.jpg")
img2 = cv2.imread("right.jpg")
result = stitch_images(img1, img2)
if result is not None:
    cv2.imshow("Panorama", result)
    cv2.waitKey(0)
    cv2.destroyAllWindows()
```

### 5.2 效果对比

| 参数 | 效果 |
|------|------|
| ratio=0.75 | 默认，好匹配数量适中 |
| ratio=0.6 | 更严格，匹配更可靠但数量少 |
| ransacReprojThreshold=5.0 | 内点容许误差 5 像素 |
| ransacReprojThreshold=3.0 | 更严格，内点要求更高 |

## 六、调试经验与避坑指南

| 问题现象 | 原因 | 解决方案 |
|----------|------|----------|
| 匹配点太少（< 4） | 图像重叠区域不够大 | 确保图像有 30%+ 重叠 |
| 拼接后图像扭曲 | 单应性矩阵计算错误 | 检查 RANSAC 阈值，过滤更多外点 |
| 拼接处有明显接缝 | 融合方式简单 | 使用多频段融合（multi-band blending） |
| findHomography 报错 | 匹配点少于 4 对 | 降低 ratio 阈值获取更多匹配 |

### 常见坑点
- **坑点1**: 拼接顺序很重要 → 先拼接相邻的图像，再逐步合并
- **坑点2**: 图像尺寸需要预先规划 → warpPerspective 的输出尺寸要足够大以容纳变换后的图像
- **坑点3**: 简单覆盖拼接会有接缝 → 实际项目中需要做融合处理

## 七、本章小结

- **必掌握**: SIFT 特征匹配 → KNN + Lowe's test → RANSAC 求单应性矩阵 → 透视变换拼接
- **选了解**: 多频段融合、多张图拼接策略
- **一句话总结**: 特征匹配 + RANSAC 排除外点 + 单应性矩阵 + 透视变换 = 全景拼接

# 第7章：图像金字塔与轮廓检测

> **对应视频**: P22-P28 | **时长**: 约48分钟 | **难度**: ★★★

## 一、核心摘要

> 图像金字塔用多分辨率表示图像，是尺度不变特征的基础；轮廓检测从二值图中提取物体边界，轮廓特征（面积、周长、近似多边形）是形状分析的核心工具；模板匹配用滑动窗口在图像中找相似区域。

- 金字塔 = 同一图像的多尺度版本，pyrDown 缩小，pyrUp 放大
- 轮廓 = 二值图中白色区域的边界，findContours 提取，drawContours 绘制
- 模板匹配 = 用模板图像在原图上滑动，找最相似的位置

## 二、知识图谱

```
本章三大模块
├── 图像金字塔
│   ├── 高斯金字塔 → pyrDown（下采样） / pyrUp（上采样）
│   └── 拉普拉斯金字塔 → 高斯金字塔相邻层之差
│
├── 轮廓检测
│   ├── findContours → 提取轮廓
│   │   ├── RETR_TREE（完整层级）
│   │   ├── RETR_EXTERNAL（仅外轮廓）
│   │   └── RETR_LIST（所有轮廓，无层级）
│   ├── drawContours → 绘制轮廓
│   ├── 轮廓特征
│   │   ├── 面积 cv2.contourArea
│   │   ├── 周长 cv2.arcLength
│   │   ├── 外接矩形 cv2.boundingRect
│   │   └── 近似多边形 cv2.approxPolyDP
│   └── 轮廓近似 → Douglas-Peucker 算法
│
└── 模板匹配
    ├── matchTemplate → 6 种匹配方法
    └── minMaxLoc → 定位最佳匹配点
```

## 三、核心概念

### 3.1 图像金字塔

**高斯金字塔**：

- **下采样（pyrDown）**: 先高斯模糊，再删除偶数行和列，尺寸减半
- **上采样（pyrUp）**: 先插入零行和零列，再高斯模糊填充，尺寸翻倍

```
原图 512×512
    ↓ pyrDown
256×256         ← 第1层
    ↓ pyrDown
128×128         ← 第2层
    ↓ pyrDown
64×64           ← 第3层
```

**拉普拉斯金字塔**：

$$L_i = G_i - \text{pyrUp}(G_{i+1})$$

即：当前层高斯 - 下一层上采样 = 当前层丢失的细节（高频信息）

### 3.2 轮廓检测

**轮廓层级关系**：

```
RETR_TREE 的层级结构:
┌─────────────────┐
│  ┌─────┐        │
│  │  ┌──┴──┐    │  ← 父子关系：外轮廓是父，内轮廓是子
│  │  │ 内  │    │
│  │  └──┬──┘    │
│  └─────┘        │
└─────────────────┘
```

| 模式 | 返回 | 用途 |
|------|------|------|
| `RETR_EXTERNAL` | 仅最外层轮廓 | 计数物体 |
| `RETR_LIST` | 所有轮廓，无层级 | 简单轮廓列表 |
| `RETR_TREE` | 所有轮廓 + 完整层级树 | 需要层级关系时 |
| `RETR_CCOMP` | 两级层级 | 区分外轮廓和内孔 |

### 3.3 轮廓特征

| 特征 | API | 说明 |
|------|-----|------|
| 面积 | `cv2.contourArea(cnt)` | 轮廓包围的区域面积 |
| 周长 | `cv2.arcLength(cnt, closed)` | closed=True 闭合轮廓 |
| 外接矩形 | `cv2.boundingRect(cnt)` | 正外接矩形 (x, y, w, h) |
| 最小外接矩形 | `cv2.minAreaRect(cnt)` | 旋转矩形，返回 (中心, 尺寸, 角度) |
| 外接圆 | `cv2.minEnclosingCircle(cnt)` | 最小包围圆 |
| 近似多边形 | `cv2.approxPolyDP(cnt, epsilon, closed)` | 用更少的顶点逼近轮廓 |

### 3.4 模板匹配

**6 种匹配方法**：

| 方法 | 公式 | 最佳值 |
|------|------|--------|
| `TM_SQDIFF` | 平方差 | **0**（最小值） |
| `TM_SQDIFF_NORMED` | 归一化平方差 | **0** |
| `TM_CCORR` | 相关性 | 最大值 |
| `TM_CCORR_NORMED` | 归一化相关性 | 最大值 |
| `TM_CCOEFF` | 相关系数 | 最大值 |
| `TM_CCOEFF_NORMED` | 归一化相关系数 | **1**（推荐） |

> **推荐**: `TM_CCOEFF_NORMED`，匹配结果 0~1，抗光照变化最好。

### 3.5 原理深入：Douglas-Peucker 轮廓近似算法

**核心思想**：用更少的顶点来近似轮廓，同时保持整体形状。

```
算法步骤:
1. 选轮廓上最远的两个点 A 和 B，连成线段 AB
2. 找轮廓上到 AB 距离最远的点 C
3. 如果 C 到 AB 的距离 > epsilon → C 是关键点，保留
4. 分别对 AC 和 CB 重复步骤 2-3（递归）
5. 如果最大距离 <= epsilon → 停止，用线段近似

实际效果:
原轮廓（100个点）                   近似后（4个点）
    ╭──────╮                          ┌──────┐
   ╱        ╲                         │      │
  │  矩形    │         →               │ 矩形 │
   ╲        ╱                         │      │
    ╰──────╯                          └──────┘

epsilon 越大 → 顶点越少 → 形状越粗糙
epsilon 越小 → 顶点越多 → 形状越精确
```

**典型应用**：检测文档的四个角点（矩形 → 4个顶点），答题卡选项的轮廓等。

### 3.6 原理深入：模板匹配的局限性

模板匹配虽然简单直观，但有三个致命缺陷：

| 缺陷 | 原因 | 影响 |
|------|------|------|
| **尺度不变性缺失** | 模板和图的大小必须一致 | 目标放大/缩小后匹配失败 |
| **旋转不变性缺失** | 只做平移滑动 | 目标旋转后匹配失败 |
| **光照敏感** | 像素值直接比较 | 亮度变化导致匹配失败 |

> 这也是为什么后面的 SIFT/SURF 等特征检测方法更强大——它们具有尺度不变性和旋转不变性。

## 四、核心 API

| API | 函数签名 | 功能 | 关键参数 |
|-----|----------|------|----------|
| `cv2.pyrDown()` | `pyrDown(src)` | 下采样 | 尺寸减半 |
| `cv2.pyrUp()` | `pyrUp(src)` | 上采样 | 尺寸翻倍 |
| `cv2.findContours()` | `findContours(img, mode, method)` | 提取轮廓 | 返回 (contours, hierarchy) |
| `cv2.drawContours()` | `drawContours(img, contours, idx, color, thickness)` | 绘制轮廓 | idx=-1 绘制全部 |
| `cv2.contourArea()` | `contourArea(cnt)` | 轮廓面积 | — |
| `cv2.arcLength()` | `arcLength(cnt, closed)` | 轮廓周长 | closed=True 闭合 |
| `cv2.approxPolyDP()` | `approxPolyDP(cnt, epsilon, closed)` | 多边形近似 | epsilon 控制近似精度 |
| `cv2.boundingRect()` | `boundingRect(cnt)` | 正外接矩形 | 返回 (x, y, w, h) |
| `cv2.matchTemplate()` | `matchTemplate(img, templ, method)` | 模板匹配 | 返回匹配结果矩阵 |
| `cv2.minMaxLoc()` | `minMaxLoc(src)` | 找最大/最小值位置 | 配合 matchTemplate 使用 |

## 五、代码实战

### 5.1 图像金字塔

```python
import cv2
import numpy as np

img = cv2.imread("lena.jpg")

# 下采样
down1 = cv2.pyrDown(img)
down2 = cv2.pyrDown(down1)

# 上采样
up1 = cv2.pyrUp(down2)  # 从 down2 放大回 down1 尺寸

cv2.imshow("Original", img)
cv2.imshow("Down 1", down1)
cv2.imshow("Down 2", down2)
cv2.imshow("Up 1", up1)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 5.2 轮廓检测与绘制

```python
# 1. 读取 → 灰度 → 二值化
img = cv2.imread("shapes.png")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
ret, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)

# 2. 提取轮廓
contours, hierarchy = cv2.findContours(binary, cv2.RETR_TREE, cv2.CHAIN_APPROX_SIMPLE)

# 3. 绘制轮廓
draw = img.copy()
cv2.drawContours(draw, contours, -1, (0, 255, 0), 2)  # -1 = 绘制全部

cv2.imshow("Contours", draw)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 5.3 轮廓特征分析

```python
for i, cnt in enumerate(contours):
    area = cv2.contourArea(cnt)           # 面积
    perimeter = cv2.arcLength(cnt, True)   # 周长
    x, y, w, h = cv2.boundingRect(cnt)    # 外接矩形

    # 多边形近似
    epsilon = 0.02 * perimeter             # 2% 周长作为近似精度
    approx = cv2.approxPolyDP(cnt, epsilon, True)

    print(f"轮廓{i}: 面积={area:.0f}, 周长={perimeter:.1f}, 顶点数={len(approx)}")

    # 根据顶点数判断形状
    if len(approx) == 4:
        print("  → 矩形")
    elif len(approx) == 3:
        print("  → 三角形")
    elif len(approx) > 8:
        print("  → 圆形")
```

### 5.4 模板匹配

```python
img = cv2.imread("scene.jpg")
template = cv2.imread("target.jpg")
h, w = template.shape[:2]

# 模板匹配（推荐 TM_CCOEFF_NORMED）
result = cv2.matchTemplate(img, template, cv2.TM_CCOEFF_NORMED)

# 找到最佳匹配位置
min_val, max_val, min_loc, max_loc = cv2.minMaxLoc(result)
top_left = max_loc  # TM_CCOEFF_NORMED 取最大值位置
bottom_right = (top_left[0] + w, top_left[1] + h)

# 绘制匹配框
cv2.rectangle(img, top_left, bottom_right, (0, 255, 0), 2)
cv2.imshow("Match Result", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 5.5 效果对比

| 操作 | 效果 | 适用场景 |
|------|------|----------|
| pyrDown 2次 | 降采样到 1/4 尺寸，丢失细节 | 多尺度分析 |
| RETR_TREE + CHAIN_APPROX_SIMPLE | 提取所有轮廓，压缩水平/垂直/对角线 | 通用轮廓提取 |
| approxPolyDP epsilon=0.02*周长 | 保留形状特征，大幅减少顶点 | 形状识别 |
| matchTemplate TM_CCOEFF_NORMED | 找到最相似区域 | 简单目标定位 |

## 六、调试经验与避坑指南

| 问题现象 | 原因 | 解决方案 |
|----------|------|----------|
| findContours 报错 | OpenCV 版本差异（返回2/3个值） | 用 `contours, hierarchy = cv2.findContours(...)` |
| 轮廓检测结果为空 | 输入不是二值图 | 先 `cv2.threshold` 二值化 |
| 轮廓面积为零 | 轮廓是退化线段 | 用 `cv2.CHAIN_APPROX_NONE` 检查 |
| 模板匹配位置不准 | 光照或尺度变化 | 用归一化方法，或改用特征匹配 |

### 常见坑点
- **坑点1**: `findContours` 会直接修改输入图像 → 传 `img.copy()` 保护原图
- **坑点2**: 轮廓检测前忘记二值化 → 先 `threshold` 或 `Canny`
- **坑点3**: `minMaxLoc` 对 SQDIFF 类方法要取最小值 → 其他方法取最大值
- **坑点4**: 模板匹配要求模板 ≤ 原图 → 否则报错

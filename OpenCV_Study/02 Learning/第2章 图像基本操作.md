# 第2章：图像基本操作

> **对应视频**: P3-P7 | **时长**: 约39分钟 | **难度**: ★☆☆

## 一、核心摘要

> 掌握图像在计算机中的本质表示（NumPy 数组），学会读取/处理视频、截取 ROI 区域、边界填充和图像数值运算。

- 图像 = 三维 NumPy 数组 (H, W, C)，每个像素值 0-255
- 视频 = 逐帧图像序列，用 `VideoCapture` 循环读取
- 数值运算注意越界裁剪（255 上限）

## 二、知识图谱

```
图像本质 (NumPy数组)
├── 形状 shape → (高度, 宽度, 通道数)
├── 像素访问 → img[y, x, c]
├── 通道操作 → split / merge / 单通道保留
├── ROI 截取 → img[y1:y2, x1:x2]
├── 边界填充 → copyMakeBorder (5种模式)
├── 数值计算 → add (取255) / addWeighted (加权融合)
└── 视频处理 → VideoCapture → 逐帧读取 → 灰度转换 → 显示
```

## 三、核心概念

### 3.1 图像本质：NumPy 数组

- **定义**: OpenCV 读取的图像就是一个 `numpy.ndarray`，三个维度分别代表 高度(H)、宽度(W)、通道数(C)
- **数据格式**: `dtype=uint8`，每个像素值范围 **0~255**
- **通道顺序**: BGR（不是 RGB！），`img[:,:,0]`=Blue, `img[:,:,1]`=Green, `img[:,:,2]`=Red

```python
img = cv2.imread("cat.jpg")
print(img.shape)   # (414, 500, 3) → 高414像素, 宽500像素, 3通道
print(img.dtype)   # uint8
print(img[0, 0])   # [B, G, R] 左上角像素值
```

### 3.2 视频读取

- **本质**: 视频就是一系列连续帧（Frame），用 `cv2.VideoCapture` 逐帧读取
- **关键**: `vc.read()` 返回 `(ret, frame)`，`ret=False` 表示视频结束

### 3.3 ROI（Region of Interest）

- **定义**: 兴趣区域，从原图中截取子区域
- **操作**: 直接用 NumPy 切片 `img[y1:y2, x1:x2]`

### 3.4 边界填充

| 模式 | 常量 | 行为 |
|------|------|------|
| 复制法 | `BORDER_REPLICATE` | 用边缘像素值填充 |
| 反射法 | `BORDER_REFLECT` | 镜像反射，边缘像素重复 |
| 反射101 | `BORDER_REFLECT_101` | 镜像反射，边缘像素不重复（默认） |
| 外包装法 | `BORDER_WRAP` | 循环平铺 |
| 常量法 | `BORDER_CONSTANT` | 用指定常量值填充 |

### 3.5 数值计算

- `cv2.add(img1, img2)`: 像素值相加，**超过 255 自动截断为 255**（饱和运算）
- `img1 + img2`: NumPy 加法，**超过 255 取模 256**（会溢出回绕，慎用！）
- `cv2.addWeighted(img1, α, img2, β, γ)`: 加权融合 = `α*img1 + β*img2 + γ`

### 3.6 原理深入：uint8 溢出与饱和运算

**为什么 255+1 会变成 0？**

`uint8` 只有 8 位二进制位，能表示的范围是 0~255（即 00000000 ~ 11111111）。当 255 再加 1：

```
255 = 11111111
+ 1 = 00000001
─────────────
= 1 00000000  → 超出的第9位被丢弃 → 结果 = 00000000 = 0
```

这就是**模 256 运算**（NumPy 的 `+` 行为）。

**cv2.add 的饱和运算**：OpenCV 检测到溢出后直接截断为 255，相当于：

```
cv2.add(152, 142) → 294 > 255 → 截断为 255
img1 + img2      → 294 % 256 → 38（颜色异常！）
```

```
直观对比（假设像素值模拟亮度）：
期望: 152 + 142 = 你应该看到更亮的区域
cv2.add:      ████████████（饱和白，合理）
NumPy +:      ██░░░░░░░░░░（异常暗，错误！）
```

**addWeighted 公式解释**：

$$\text{dst} = \alpha \cdot \text{img1} + \beta \cdot \text{img2} + \gamma$$

| 参数 | 含义 | 典型值 |
|------|------|--------|
| α | 第一张图的权重 | 0.0~1.0 |
| β | 第二张图的权重 | 0.0~1.0 |
| γ | 亮度偏移量（标量） | 0 |

> 当 α+β=1 时，融合后亮度不变；当 α+β<1 时变暗；当 α+β>1 时变亮。

### 3.7 原理深入：视频的本质

视频文件 = **编码后的帧序列 + 音频轨道**，每一帧本质就是一张图像。

```
视频文件(.mp4)
├── 视频轨道
│   ├── 帧1 → 帧2 → 帧3 → ... → 帧N
│   │   (每帧 = H×W×3 的像素矩阵)
│   └── 编码格式: H.264 / H.265 / MPEG-4
├── 音频轨道
└── 元数据（FPS, 时长, 分辨率）
```

**关键概念**：

| 概念 | 含义 | 示例 |
|------|------|------|
| FPS | 每秒帧数（Frames Per Second） | 30fps = 每秒30帧 |
| 帧间隔 | 一帧的显示时间 | 30fps → 每帧约 33ms |
| `waitKey(10)` | 每帧显示后等待 10ms | 10ms < 33ms → 实际播放可能比原速快 |

> `waitKey` 的值影响播放速度，越小越快，设为 1 时接近极限速度。

### 3.8 原理深入：cv2.split 的性能陷阱

`cv2.split` 会为每个通道创建**独立的内存副本**（深拷贝），对于大图这很昂贵：

```python
# ❌ 慢：创建三个独立数组
b, g, r = cv2.split(img)

# ✅ 快：零拷贝视图，共享内存
b = img[:, :, 0]  # 直接引用原数组的 Blue 通道
g = img[:, :, 1]
r = img[:, :, 2]
```

**注意**：切片方式获取的通道是视图，修改会影响原图；`cv2.split` 是副本，修改不影响原图。根据需求选择。

### 3.9 原理深入：图像缩放与插值

`cv2.resize` 在改变尺寸时必须"猜测"新像素值，这个猜测过程叫**插值**：

| 插值方法 | 常量 | 原理 | 适用场景 |
|----------|------|------|----------|
| 最近邻 | `INTER_NEAREST` | 取最近像素值 | 速度最快，质量最差 |
| 双线性 | `INTER_LINEAR` | 周围4像素加权平均（默认） | 通用缩放 |
| 双三次 | `INTER_CUBIC` | 周围16像素三次多项式拟合 | 放大时质量更好 |
| Lanczos | `INTER_LANCZOS4` | 周围64像素 sinc 函数插值 | 缩小降采样最佳 |

## 四、核心 API

| API | 函数签名 | 功能 | 关键参数 |
|-----|----------|------|----------|
| `cv2.VideoCapture()` | `VideoCapture(path)` | 打开视频文件或摄像头 | path: 文件路径/设备号(0=默认摄像头) |
| `vc.read()` | `read()` | 逐帧读取 | 返回 `(ret, frame)` |
| `vc.isOpened()` | `isOpened()` | 检查是否成功打开 | — |
| `vc.release()` | `release()` | 释放资源 | 必须调用！ |
| `cv2.cvtColor()` | `cvtColor(img, code)` | 颜色空间转换 | `COLOR_BGR2GRAY` 等 |
| `cv2.split()` | `split(img)` | 分离三通道 | 返回 `(b, g, r)` |
| `cv2.merge()` | `merge([b,g,r])` | 合并三通道 | 注意顺序 BGR |
| `cv2.copyMakeBorder()` | `copyMakeBorder(img, top, bottom, left, right, borderType)` | 边界填充 | 5种borderType |
| `cv2.add()` | `add(img1, img2)` | 饱和加法 | 超255截断为255 |
| `cv2.addWeighted()` | `addWeighted(img1, α, img2, β, γ)` | 加权融合 | α+β=1时效果最佳 |
| `cv2.resize()` | `resize(img, dsize, fx, fy)` | 缩放图像 | 用于融合前统一尺寸 |

## 五、代码实战

### 5.1 视频读取与灰度处理

```python
import cv2

vc = cv2.VideoCapture("test.mp4")

# 检查是否打开成功
if vc.isOpened():
    open_flag, frame = vc.read()
else:
    open_flag = False

while open_flag:
    ret, frame = vc.read()
    if frame is None:
        break
    if ret:
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        cv2.imshow("result", gray)
        if cv2.waitKey(10) & 0xFF == 27:  # 按 ESC 退出
            break

vc.release()
cv2.destroyAllWindows()
```

### 5.2 ROI 截取

```python
img = cv2.imread("cat.jpg")
# 截取左上角 200x200 区域
roi = img[0:200, 0:200]
cv_show("ROI", roi)
```

### 5.3 通道操作

```python
# 分离通道
b, g, r = cv2.split(img)

# 只保留 R 通道（B=0, G=0）
cur_img = img.copy()
cur_img[:, :, 0] = 0   # Blue 通道清零
cur_img[:, :, 1] = 0   # Green 通道清零
cv_show("R channel only", cur_img)
```

### 5.4 边界填充

```python
top, bottom, left, right = (50, 50, 50, 50)

replicate  = cv2.copyMakeBorder(img, top, bottom, left, right, cv2.BORDER_REPLICATE)
reflect    = cv2.copyMakeBorder(img, top, bottom, left, right, cv2.BORDER_REFLECT)
reflect101 = cv2.copyMakeBorder(img, top, bottom, left, right, cv2.BORDER_REFLECT_101)
wrap       = cv2.copyMakeBorder(img, top, bottom, left, right, cv2.BORDER_WRAP)
constant   = cv2.copyMakeBorder(img, top, bottom, left, right, cv2.BORDER_CONSTANT, value=0)
```

### 5.5 图像融合

```python
# 先统一尺寸
img_cat = cv2.resize(img_cat, (500, 414))
img_dog = cv2.resize(img_dog, (500, 414))

# 加权融合：猫 0.4 + 狗 0.6
res = cv2.addWeighted(img_cat, 0.4, img_dog, 0.6, 0)
cv_show("Blended", res)
```

### 5.6 效果对比

| 操作 | 效果 | 适用场景 |
|------|------|----------|
| `cv2.add` vs NumPy `+` | add 截断255，NumPy 取模256溢出 | 永远用 cv2.add |
| `BORDER_REPLICATE` | 边缘像素复制，颜色无突变 | 大多数场景 |
| `BORDER_REFLECT_101` | 镜像边界，无重复边缘像素 | 默认方法 |
| `BORDER_CONSTANT` | 纯色填充 | 需要固定背景色的场景 |

## 六、调试经验与避坑指南

| 问题现象 | 原因 | 解决方案 |
|----------|------|----------|
| 视频读取后显示灰色 | 忘记 `cv2.waitKey()` → 窗口无刷新 | 必须加 `cv2.waitKey(10)` |
| `vc.read()` 返回 None | 视频已读完或文件不存在 | 检查 `isOpened()` 和 `frame is None` |
| 图像融合报错尺寸不一致 | 两张图 shape 不同 | 先 `cv2.resize` 统一尺寸 |
| 通道分离后颜色诡异 | 搞混了 BGR 顺序 | 牢记 B=0, G=1, R=2 |

### 常见坑点
- **坑点1**: 图像融合时用 `img1 + img2` 而非 `cv2.add` → 像素超 255 会溢出产生异常颜色
- **坑点2**: 视频处理完忘记 `vc.release()` → 资源泄漏，可能导致下次打不开视频
- **坑点3**: `cv2.split` 很慢（深拷贝），如需只读单通道用 `img[:,:,0]` 切片

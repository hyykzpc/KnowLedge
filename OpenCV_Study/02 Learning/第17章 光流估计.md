# 第17章：光流估计

> **对应视频**: P77-P78（课程尾部） | **时长**: 约30分钟 | **难度**: ★★★★

## 一、核心摘要

> 光流（Optical Flow）是图像中像素运动的瞬时速度场。Lucas-Kanade 是经典的稀疏光流算法，基于三个假设（亮度恒定、小运动、空间一致），通过最小二乘法求解运动向量。稠密光流（Farneback）则计算每个像素的运动。

## 二、知识图谱

```
光流估计
├── 稀疏光流 → 只跟踪特征点
│   └── Lucas-Kanade (LK)
│       ├── 三个假设条件
│       │   ├── 亮度恒定: 同一点在不同帧亮度不变
│       │   ├── 小运动: 相邻帧间位移很小
│       │   └── 空间一致: 邻域像素运动一致
│       ├── 数学: 最小二乘法求解
│       └── 金字塔 LK: 解决大运动问题
│
├── 稠密光流 → 每个像素都计算
│   └── Farneback
│       └── 多项式展开近似
│
└── 应用
    ├── 运动估计
    ├── 目标追踪
    ├── 视频稳定
    └── 动作识别
```

## 三、核心概念

### 3.1 光流基本方程

**亮度恒定假设**：$I(x,y,t) = I(x+dx, y+dy, t+dt)$

泰勒展开并化简，得到**光流约束方程**：

$$I_x u + I_y v + I_t = 0$$

其中：
- $I_x, I_y$ = 空间梯度
- $I_t$ = 时间梯度
- $(u, v)$ = 光流向量（待求）

**一个问题，两个未知数**：一个方程求两个未知数，有无穷多解。这就是**孔径问题**（Aperture Problem）。

### 3.2 Lucas-Kanade 方法

**解决孔径问题的关键**：第三个假设——**空间一致性**（邻域像素运动相同）。

在一个 $n \times n$ 窗口内，所有像素有相同的 $(u, v)$：

$$\begin{bmatrix} I_x(p_1) & I_y(p_1) \\ I_x(p_2) & I_y(p_2) \\ \vdots & \vdots \end{bmatrix} \begin{bmatrix} u \\ v \end{bmatrix} = -\begin{bmatrix} I_t(p_1) \\ I_t(p_2) \\ \vdots \end{bmatrix}$$

用最小二乘法求解：

$$\begin{bmatrix} u \\ v \end{bmatrix} = (A^T A)^{-1} A^T b$$

### 3.3 金字塔 LK

**问题**：LK 假设"小运动"，但实际中物体可能移动很大。

**解决**：金字塔 LK —— 在低分辨率图像上先估计大运动，再到高分辨率上细化。

```
原图 512×512  → 估计大运动方向
    ↓ pyrDown
256×256  → 细化运动估计
    ↓ pyrDown
128×128  → 进一步细化
    ↓ pyrDown
64×64   → 最粗糙的运动估计（能处理大运动）
```

### 3.4 原理深入：角点选择对 LK 的重要性

LK 光流需要跟踪"好"的特征点。什么样的点是好特征点？

```
边缘上的点:                      角点:
    ┌─────┐                       ┌─────┐
    │▓▓░░░│                       │▓▓░░░│
    │▓▓░░░│  ← 沿边缘方向无法确定   │▓▓░░░│  ← 所有方向都能确定运动
    │▓▓░░░│                       │▓▓░░░│
    └─────┘                       └─────┘
    → 孔径问题严重                  → 孔径问题最小
```

**结论**：LK 光流常用 `cv2.goodFeaturesToTrack`（Shi-Tomasi 角点检测）来选择初始跟踪点。

### 3.5 原理深入：稀疏光流 vs 稠密光流

| 特性 | 稀疏光流 (LK) | 稠密光流 (Farneback) |
|------|-------------|---------------------|
| 计算范围 | 仅特征点 | 每个像素 |
| 速度 | 快 | 慢 |
| 应用 | 目标追踪、特征跟踪 | 视频分割、运动分析 |
| 输出 | 点列表 + 运动向量 | 每个像素的运动向量图 |

## 四、核心 API

| API | 函数签名 | 功能 | 关键参数 |
|-----|----------|------|----------|
| `cv2.goodFeaturesToTrack()` | `goodFeaturesToTrack(img, maxCorners, qualityLevel, minDistance)` | 提取好角点 | maxCorners=100, qualityLevel=0.3 |
| `cv2.calcOpticalFlowPyrLK()` | `calcOpticalFlowPyrLK(prev, next, prevPts, nextPts, status, err)` | 金字塔 LK 光流 | winSize=(15,15), maxLevel=2 |
| `cv2.calcOpticalFlowFarneback()` | `calcOpticalFlowFarneback(prev, next, flow, ...)` | 稠密光流 | 返回每个像素的运动向量 |

## 五、代码实战

### 5.1 稀疏光流（LK 金字塔）

```python
import cv2
import numpy as np

cap = cv2.VideoCapture("video.mp4")

# 参数
feature_params = dict(maxCorners=100, qualityLevel=0.3, minDistance=7, blockSize=7)
lk_params = dict(winSize=(15, 15), maxLevel=2,
                 criteria=(cv2.TERM_CRITERIA_EPS | cv2.TERM_CRITERIA_COUNT, 10, 0.03))

# 读取第一帧，检测角点
ret, old_frame = cap.read()
old_gray = cv2.cvtColor(old_frame, cv2.COLOR_BGR2GRAY)
p0 = cv2.goodFeaturesToTrack(old_gray, mask=None, **feature_params)

# 创建掩膜用于绘制轨迹
mask = np.zeros_like(old_frame)

while True:
    ret, frame = cap.read()
    if not ret:
        break

    frame_gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)

    # 计算光流
    p1, st, err = cv2.calcOpticalFlowPyrLK(old_gray, frame_gray, p0, None, **lk_params)

    if p1 is not None:
        # 筛选成功跟踪的点
        good_new = p1[st == 1]
        good_old = p0[st == 1]

        # 绘制轨迹
        for i, (new, old) in enumerate(zip(good_new, good_old)):
            a, b = new.ravel()
            c, d = old.ravel()
            mask = cv2.line(mask, (int(a), int(b)), (int(c), int(d)), (0, 255, 0), 2)
            frame = cv2.circle(frame, (int(a), int(b)), 5, (0, 0, 255), -1)

        img = cv2.add(frame, mask)
        cv2.imshow("Optical Flow", img)

    # 更新
    old_gray = frame_gray.copy()
    p0 = good_new.reshape(-1, 1, 2)

    if cv2.waitKey(30) & 0xFF == 27:
        break

cap.release()
cv2.destroyAllWindows()
```

### 5.2 稠密光流（Farneback）

```python
# 读取两帧
prev_gray = cv2.cvtColor(prev_frame, cv2.COLOR_BGR2GRAY)
next_gray = cv2.cvtColor(next_frame, cv2.COLOR_BGR2GRAY)

# 计算稠密光流
flow = cv2.calcOpticalFlowFarneback(prev_gray, next_gray, None,
                                    0.5, 3, 15, 3, 5, 1.2, 0)

# 将光流向量转为 HSV 可视化
mag, ang = cv2.cartToPolar(flow[..., 0], flow[..., 1])
hsv = np.zeros((prev_gray.shape[0], prev_gray.shape[1], 3), dtype=np.uint8)
hsv[..., 0] = ang * 180 / np.pi / 2    # 色调 = 运动方向
hsv[..., 1] = 255                       # 饱和度
hsv[..., 2] = cv2.normalize(mag, None, 0, 255, cv2.NORM_MINMAX)  # 亮度 = 运动速度

bgr = cv2.cvtColor(hsv, cv2.COLOR_HSV2BGR)
cv2.imshow("Dense Optical Flow", bgr)
```

### 5.3 效果对比

| 方法 | 效果 | 适用场景 |
|------|------|----------|
| 稀疏光流 + 金字塔 | 跟踪特征点轨迹，速度快 | 目标追踪、特征跟踪 |
| 稠密光流 | 每个像素的速度和方向，可视化直观 | 运动分析、视频分割 |

## 六、调试经验与避坑指南

| 问题现象 | 原因 | 解决方案 |
|----------|------|----------|
| 跟踪点越来越少 | 特征点漂移出画面或被遮挡 | 定期重新检测角点 |
| 跟踪点漂移 | 窗口太小或金字塔层级不够 | 增大 winSize 或 maxLevel |
| 稠密光流计算慢 | 像素太多 | 先缩小图像再计算 |
| 光流方向混乱 | 运动太大超出 LK 假设 | 增大金字塔层级 |

### 常见坑点
- **坑点1**: `goodFeaturesToTrack` 需要灰度图输入
- **坑点2**: `p0` 必须是 float32 类型，shape 为 (N, 1, 2)
- **坑点3**: 跟踪点丢失后需要重新检测 → 当 `good_new` 数量 < 阈值时重新初始化

- **必掌握**: LK 光流三个假设、金字塔 LK 的使用、稀疏光流跟踪流程

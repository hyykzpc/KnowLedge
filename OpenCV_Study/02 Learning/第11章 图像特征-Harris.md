# 第11章：图像特征-Harris 角点检测

> **对应视频**: P46-P50 | **时长**: 约43分钟 | **难度**: ★★★★

## 一、核心摘要

> Harris 角点检测通过分析窗口在各个方向移动时的灰度变化，来判断一个点是角点、边缘还是平坦区域。它是特征检测的基石，后续的 SIFT 等算法都建立在此基础上。

- 角点 = 窗口向任意方向移动，灰度都发生剧烈变化的点
- 核心工具：自相关矩阵 M 的特征值 λ₁、λ₂
- 角点响应函数 R = det(M) - k·trace²(M)

## 二、知识图谱

```
Harris 角点检测
├── 基本思想
│   └── 窗口在图像上滑动，观察灰度变化
│
├── 三种情况
│   ├── 平坦区域: 窗口向任何方向移动，灰度基本不变 → 无特征
│   ├── 边缘: 沿边缘方向移动不变，垂直方向变化大 → 一边缘特征
│   └── 角点: 窗口向任何方向移动，灰度都变化大 → 角点！
│
├── 数学工具
│   ├── 自相关矩阵 M → 描述窗口在各方向的灰度变化
│   ├── 特征值 λ₁, λ₂ → 判断属于哪种情况
│   └── 角点响应函数 R → 简化计算，避免特征值分解
│
└── OpenCV 实现
    └── cv2.cornerHarris → 一行代码搞定
```

## 三、核心概念

### 3.1 核心思想：窗口滑动

```
窗口在平坦区域:          窗口在边缘:            窗口在角点:
┌─────┐                 ┌─────┐                ┌─────┐
│▓▓▓▓▓│                 │▓▓░░░│                │▓▓░░░│
│▓▓▓▓▓│  ← 不动          │▓▓░░░│  ← 上下不变     │▓▓░░░│  ← 上下左右都变
│▓▓▓▓▓│                 │▓▓░░░│    左右变       │▓▓░░░│
└─────┘                 └─────┘                └─────┘
→ 灰度无变化              → 沿边缘无变化           → 所有方向都有变化
→ 平坦区域                → 边缘                  → 角点！
```

### 3.2 数学推导

**窗口移动产生的灰度变化**：

$$E(u, v) = \sum_{(x,y) \in W} w(x,y) \cdot [I(x+u, y+v) - I(x,y)]^2$$

泰勒展开后化简为：

$$E(u, v) \approx [u, v] \cdot M \cdot \begin{bmatrix} u \\ v \end{bmatrix}$$

其中 **自相关矩阵 M**：

$$M = \sum_{(x,y)} w(x,y) \begin{bmatrix} I_x^2 & I_x I_y \\ I_x I_y & I_y^2 \end{bmatrix}$$

### 3.3 特征值分析

| 情况 | λ₁ | λ₂ | 含义 |
|------|-----|-----|------|
| 平坦区域 | 小 | 小 | 两个方向灰度变化都小 |
| 边缘 | 大 | 小 | 一个方向变化大，一个方向变化小 |
| 角点 | 大 | 大 | 两个方向灰度变化都大 |

### 3.4 角点响应函数 R

为了避免计算特征值（开销大），Harris 提出了角点响应函数：

$$R = \det(M) - k \cdot \text{trace}^2(M)$$

其中：
- $\det(M) = \lambda_1 \cdot \lambda_2$
- $\text{trace}(M) = \lambda_1 + \lambda_2$
- $k$ 是经验常数，通常取 0.04~0.06

| R 值 | 含义 |
|------|------|
| R 大正数 | 角点 |
| R 大负数 | 边缘 |
| \|R\| 很小 | 平坦区域 |

### 3.5 原理深入：为什么需要自相关矩阵？

**直接问题**：如何量化"窗口移动后灰度变化"？

**解决方案**：自相关矩阵 M 的每个元素都有明确的物理意义：

| 元素 | 含义 |
|------|------|
| M[0,0] = ΣIx² | x 方向梯度的平方和 → x 方向的变化程度 |
| M[1,1] = ΣIy² | y 方向梯度的平方和 → y 方向的变化程度 |
| M[0,1] = ΣIx·Iy | x 和 y 梯度的协方差 → 两个方向的关联程度 |

**几何理解**：M 的特征向量代表灰度变化最快的两个方向，特征值代表变化的强度。

### 3.6 原理深入：Harris 的优缺点

| 优点 | 缺点 |
|------|------|
| 计算简单，速度快 | 不具有尺度不变性（放大后角点可能变成边缘） |
| 旋转不变性（角点旋转后仍是角点） | 对参数 k 敏感 |
| 对光照变化有一定鲁棒性 | 检测结果需要 NMS 后处理 |

## 四、核心 API

| API | 函数签名 | 功能 | 关键参数 |
|-----|----------|------|----------|
| `cv2.cornerHarris()` | `cornerHarris(src, blockSize, ksize, k)` | Harris 角点检测 | blockSize=窗口大小, ksize=Sobel核, k=0.04 |

## 五、代码实战

### 5.1 基础 Harris 检测

```python
import cv2
import numpy as np

img = cv2.imread("chessboard.jpg")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
gray = np.float32(gray)  # cornerHarris 要求 float32

# Harris 角点检测
dst = cv2.cornerHarris(gray, blockSize=2, ksize=3, k=0.04)

# 膨胀标记点，使其更明显
dst = cv2.dilate(dst, None)

# 阈值筛选：R > 0.01 * max(R) 标记为角点
img[dst > 0.01 * dst.max()] = [0, 0, 255]  # 红色标记

cv2.imshow("Harris Corners", img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 5.2 参数对比

```python
# 不同 k 值的效果对比
for k in [0.02, 0.04, 0.06, 0.08]:
    dst = cv2.cornerHarris(gray, 2, 3, k)
    img_copy = img.copy()
    img_copy[dst > 0.01 * dst.max()] = [0, 0, 255]
    cv2.imshow(f"k={k}", img_copy)
```

### 5.3 效果对比

| 参数设置 | 效果描述 | 适用场景 |
|----------|----------|----------|
| blockSize=2, k=0.04 | 默认设置，角点适中 | 通用场景 |
| blockSize=3, k=0.04 | 窗口更大，抗噪更强 | 噪声较多的图像 |
| k=0.02 | 更多角点被检出 | 需要更多特征点 |
| k=0.06 | 更严格的角点标准 | 需要更可靠的特征点 |

## 六、调试经验与避坑指南

| 问题现象 | 原因 | 解决方案 |
|----------|------|----------|
| 检测不到角点 | 阈值太高 | 降低阈值，如 0.001*dst.max() |
| 角点太多，全是噪点 | 阈值太低或 k 太小 | 提高阈值或增大 k |
| 输入报错 | 数据类型不对 | 用 np.float32 转换 |
| 角点标记不清晰 | 标记点太小 | dilate 膨胀后再标记 |

### 常见坑点
- **坑点1**: `cornerHarris` 输入必须是 float32 → 用 `np.float32(gray)` 转换
- **坑点2**: 返回值不是二值图，而是每个像素的 R 值 → 需要阈值筛选
- **坑点3**: 角点可能聚集在一起 → 需要用 NMS 或 dilate 后处理

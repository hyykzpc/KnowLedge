## 三、核心概念

### 3.1 OpenCV 简介

- **定义**: OpenCV（Open Source Computer Vision Library）是跨平台计算机视觉库，由 Intel 发起，支持 C++/Python/Java 等多语言
- **两大版本**:
  - `opencv-python`: 主模块，包含所有核心图像处理功能
  - `opencv-contrib-python`: 扩展模块，包含 SIFT/SURF 等专利算法（课程后期需要）
- **课程覆盖**: 图像处理基础 → 特征检测 → 视频分析 → DNN 深度学习推理 → 6个实战项目

### 3.2 安装配置

| 组件 | 安装命令 | 说明 |
|------|----------|------|
| OpenCV 主库 | `pip install opencv-python` | 核心功能 |
| OpenCV 扩展 | `pip install opencv-contrib-python` | 含 SIFT 等扩展算法 |

### 3.3 原理深入：BGR 通道顺序的由来

**为什么 OpenCV 用 BGR 而不是 RGB？**

这要从历史说起。早期视频采集设备（如摄像头）和图像编码标准（如 JPEG）在硬件层面就是按 BGR 顺序处理像素的。Intel 在开发 OpenCV 时沿用了这一硬件惯例，避免了额外的通道重排开销。

```
人类直觉:  R → G → B
OpenCV:    B → G → R  （与硬件一致）
Matplotlib: R → G → B  （与人类直觉一致）
```

**实际影响**：当你用 `cv2.imread` 读取图像后用 `matplotlib` 显示，颜色会反相（红蓝互换）。解决方案：

```python
# 方法1：转换通道顺序
img_rgb = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2RGB)

# 方法2：直接用 cv2.imshow（OpenCV 原生显示，不会反相）
cv2.imshow("correct", img_bgr)
```

### 3.4 原理深入：图像在内存中的存储

**Mat 对象（C++ 层面）**

OpenCV 的 C++ 核心类 `cv::Mat` 本质上是一个**矩阵头 + 数据指针**的结构：

```
Mat 对象
├── 矩阵头（固定大小 96 字节）
│   ├── rows, cols（尺寸）
│   ├── type（数据类型，如 CV_8UC3）
│   ├── step（每行字节数）
│   └── *data（指向像素数据的指针）
└── 像素数据块（在堆上分配）
    └── B₀ G₀ R₀ B₁ G₁ R₁ ...（按行连续存储）
```

**Python 层面**：`cv2.imread` 返回的 `numpy.ndarray` 是对 C++ Mat 数据的**零拷贝包装**，这也是为什么 OpenCV 和 NumPy 能无缝协作——它们共享同一块内存。

**uint8 的意义**：每个像素值用 8 位无符号整数存储（0-255），这是为了在精度和内存之间取得平衡：
- 256 级灰度足够人眼分辨（人眼约能分辨 200 级）
- 三个通道正好 3 字节 = 24 位真彩色
- 一张 1920×1080 的彩色图 = 1920×1080×3 ≈ 6MB，内存友好

## 四、核心 API

| API | 函数签名 | 功能 | 说明 |
|-----|----------|------|------|
| `cv2.__version__` | 属性 | 查看 OpenCV 版本 | 验证安装是否成功 |
| `cv2.imread()` | `imread(path, flags)` | 读取图像 | flags: cv2.IMREAD_COLOR(默认) / IMREAD_GRAYSCALE |
| `cv2.imshow()` | `imshow(winname, img)` | 显示图像 | 需配合 waitKey 使用 |
| `cv2.waitKey()` | `waitKey(delay)` | 等待键盘输入 | 0=无限等待, >0=等待毫秒数 |
| `cv2.destroyAllWindows()` | — | 关闭所有窗口 | 程序结束前清理资源 |

## 五、代码实战

### 5.1 验证安装 + 第一个程序

```python
import cv2
import numpy as np

# 1. 验证版本
print(f"OpenCV 版本: {cv2.__version__}")
print(f"NumPy 版本: {np.__version__}")

# 2. 读取并显示图像
img = cv2.imread("test.jpg")          # 默认 BGR 彩色读取
print(f"图像尺寸 (H, W, C): {img.shape}")  # (高, 宽, 通道数)

cv2.imshow("My First Image", img)     # 显示窗口
cv2.waitKey(0)                         # 按任意键关闭
cv2.destroyAllWindows()
```

### 5.2 辅助函数（课程常用）

```python
def cv_show(name, img):
    """快速显示图像的工具函数，整个课程都会用到"""
    cv2.imshow(name, img)
    cv2.waitKey(0)
    cv2.destroyAllWindows()
```

## 六、调试经验与避坑指南

### 常见坑点
- **坑点1**: 图像路径含中文 → OpenCV 的 imread 对中文路径支持差，用 `np.fromfile` + `cv2.imdecode` 替代
- **坑点2**: `opencv-python` 和 `opencv-contrib-python` 同时安装 → 包冲突，卸载全部后只装一个
- **坑点3**: Jupyter 中 `cv2.imshow` 卡死 → Jupyter 中建议用 `matplotlib.pyplot.imshow` 替代
- **坑点4**: BGR 通道顺序 → OpenCV 默认 BGR 而非 RGB，用 matplotlib 显示时需转换：`cv2.cvtColor(img, cv2.COLOR_BGR2RGB)`

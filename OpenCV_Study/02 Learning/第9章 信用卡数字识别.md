# 第9章：项目实战-信用卡数字识别

> **对应视频**: P35-P40 | **时长**: 约50分钟 | **难度**: ★★★

## 一、核心摘要

> 第一个完整项目：对信用卡图像进行预处理，用模板匹配识别卡面上的数字。核心流程：数字模板处理 → 卡片预处理 → 分组匹配 → 输出结果。

## 二、项目 Pipeline

```
输入: 信用卡图像 + 数字模板(0-9)
    ↓
┌─────────────────────────────────────┐
│ 1. 模板处理                          │
│    读取模板 → 灰度 → 二值化 → 轮廓   │
│    按轮廓排序 → 得到 0-9 共10个模板  │
├─────────────────────────────────────┤
│ 2. 卡片预处理                        │
│    读取卡片 → 灰度 → 礼帽(去光照)     │
│    → Sobel梯度 → 闭运算(连数字)       │
│    → 二值化 → 闭运算(填孔) → 轮廓     │
├─────────────────────────────────────┤
│ 3. 数字区域提取                      │
│    筛选合适轮廓 → 按坐标排序          │
│    → 分组(4个数字一组) → 外接矩形     │
├─────────────────────────────────────┤
│ 4. 模板匹配识别                      │
│    每个数字区域 → 与10个模板逐一匹配   │
│    → 取最高分 → 输出数字              │
└─────────────────────────────────────┘
    ↓
输出: 识别的卡号
```

## 三、核心步骤详解

### 3.1 模板预处理

**关键点**：将 0-9 的数字模板按轮廓的外接矩形排序，确保第 0 个轮廓对应数字 0。

```python
# 模板排序的关键
ref_cnts = sorted(contours, key=lambda c: cv2.boundingRect(c)[0])
# 按 x 坐标排序 → contours[0]=数字0, contours[1]=数字1, ...
```

### 3.2 卡片预处理（形态学组合拳）

这是整个项目的核心，使用了多种形态学操作的组合：

```
礼帽: 原图 - 开运算 → 提取亮色数字，去除光照影响
     ↓
Sobel梯度: 突出数字边缘
     ↓
闭运算1: 将数字边缘连接成块
     ↓
二值化: 转为黑白图
     ↓
闭运算2: 填充数字块内部孔洞
```

**为什么用礼帽？** 信用卡表面有光泽，光照不均影响数字检测。礼帽能提取比背景更亮的区域（数字），同时消除整体光照变化。

### 3.3 数字区域分组

信用卡卡号通常是 4 组 × 4 位数字，需要按位置分组：

```python
# 1. 按 x 坐标排序所有数字轮廓
dight_cnts = sorted(contours, key=lambda c: cv2.boundingRect(c)[0])

# 2. 每 4 个一组（16 个数字分 4 组）
for i in range(0, len(dight_cnts), 4):
    group = dight_cnts[i:i+4]
    # 处理每组...
```

### 3.4 模板匹配识别

每个数字区域与 10 个模板逐一匹配，得分最高的即为识别结果：

```python
# 对每个待识别的数字区域
for roi in digit_rois:
    scores = []
    for template in templates:
        result = cv2.matchTemplate(roi, template, cv2.TM_CCOEFF)
        scores.append(cv2.minMaxLoc(result)[1])  # 取最大值
    digit = np.argmax(scores)  # 最高分对应的模板编号
```

## 四、核心 API

| API | 本章新用法 | 作用 |
|-----|-----------|------|
| `cv2.morphologyEx` | MORPH_TOPHAT | 礼帽提取亮色数字 |
| `cv2.Sobel` | 梯度计算 | 突出数字边缘 |
| `cv2.morphologyEx` | MORPH_CLOSE | 闭运算连接数字块 |
| `cv2.matchTemplate` | TM_CCOEFF | 与模板逐一匹配 |
| `cv2.boundingRect` | 排序轮廓 | 按位置排序数字 |

## 五、代码实战

### 5.1 完整流程骨架

```python
import cv2
import numpy as np

def cv_show(name, img):
    cv2.imshow(name, img)
    cv2.waitKey(0)
    cv2.destroyAllWindows()

# ====== 1. 模板处理 ======
template = cv2.imread("ocr_a_reference.png")
ref_gray = cv2.cvtColor(template, cv2.COLOR_BGR2GRAY)
ref_binary = cv2.threshold(ref_gray, 10, 255, cv2.THRESH_BINARY_INV)[1]

ref_cnts, _ = cv2.findContours(ref_binary.copy(), cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
ref_cnts = sorted(ref_cnts, key=lambda c: cv2.boundingRect(c)[0])

digits = {}  # {0: roi_0, 1: roi_1, ..., 9: roi_9}
for i, cnt in enumerate(ref_cnts):
    x, y, w, h = cv2.boundingRect(cnt)
    digits[i] = ref_binary[y:y+h, x:x+w]

# ====== 2. 卡片预处理 ======
card = cv2.imread("credit_card.jpg")
card_gray = cv2.cvtColor(card, cv2.COLOR_BGR2GRAY)

# 礼帽 → 提取亮色数字
kernel = np.ones((9, 3), np.uint8)  # 注意：宽高比适应数字形状
tophat = cv2.morphologyEx(card_gray, cv2.MORPH_TOPHAT, kernel)

# Sobel 梯度
grad_x = cv2.Sobel(tophat, cv2.CV_32F, 1, 0, ksize=3)
grad_x = np.absolute(grad_x)
grad_x = cv2.normalize(grad_x, None, 0, 255, cv2.NORM_MINMAX)
grad_x = np.uint8(grad_x)

# 闭运算 → 连接数字块
kernel_close = np.ones((5, 5), np.uint8)
grad_close = cv2.morphologyEx(grad_x, cv2.MORPH_CLOSE, kernel_close)

# 二值化 + 闭运算填孔
_, binary = cv2.threshold(grad_close, 0, 255, cv2.THRESH_BINARY | cv2.THRESH_OTSU)
binary_close = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel_close)

# ====== 3. 提取数字区域 ======
cnts, _ = cv2.findContours(binary_close.copy(), cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
digit_cnts = []

for cnt in cnts:
    x, y, w, h = cv2.boundingRect(cnt)
    ratio = w / h
    # 筛选条件：宽高比合适，面积合适
    if 2.5 < ratio < 4.0 and 0.02 < cv2.contourArea(cnt) / (card.shape[0]*card.shape[1]) < 0.2:
        digit_cnts.append(cnt)

digit_cnts = sorted(digit_cnts, key=lambda c: cv2.boundingRect(c)[0])

# ====== 4. 模板匹配识别 ======
output = []
for i, cnt in enumerate(digit_cnts):
    x, y, w, h = cv2.boundingRect(cnt)
    roi = binary[y-5:y+h+5, x-5:x+w+5]  # 留边距

    scores = []
    for digit_val, template_roi in digits.items():
        result = cv2.matchTemplate(roi, template_roi, cv2.TM_CCOEFF)
        scores.append(cv2.minMaxLoc(result)[1])

    output.append(str(np.argmax(scores)))

print("识别结果:", "".join(output))
```

## 六、调试经验与避坑指南

| 问题现象 | 原因 | 解决方案 |
|----------|------|----------|
| 数字轮廓检测不到 | 闭运算核太小 | 增大闭运算核到 (5,5) 或 (7,7) |
| 检测到太多非数字轮廓 | 筛选条件太宽松 | 收紧宽高比和面积阈值 |
| 模板匹配识别错误 | 数字区域形状与模板差异大 | 确保 ROI 和模板都做了相同的二值化处理 |
| 礼帽后数字反而不明显 | 核大小不合适 | 核宽应匹配数字宽度，核高应匹配数字高度 |

### 常见坑点
- **坑点1**: 模板轮廓排序错误 → 必须用 `cv2.boundingRect(cnt)[0]`（x坐标）排序，确保 0-9 对应
- **坑点2**: 卡片预处理和模板预处理的二值化方式必须一致
- **坑点3**: 形态学核的尺寸是关键 → 礼帽核 (9,3) 适应数字形状，闭运算核 (5,5) 适应连接需求

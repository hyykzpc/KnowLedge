# 第5章：图像梯度计算

> **对应视频**: P16-P18 | **时长**: 约24分钟 | **难度**: ★★☆

## 一、核心摘要

> 图像梯度是像素值变化的速度和方向，是边缘检测的基础。Sobel、Scharr、Laplacian 是三种经典梯度算子，分别用一阶和二阶导数来捕捉亮度变化。

- 梯度大的地方 = 像素值剧烈变化的地方 = 边缘
- Sobel 算子 = 一阶导数，最常用
- Laplacian 算子 = 二阶导数，对噪声敏感

## 二、知识图谱

```
图像梯度
├── 一阶导数（变化率）
│   ├── Sobel 算子 → 水平梯度 Gx / 垂直梯度 Gy
│   ├── Scharr 算子 → Sobel 的增强版，核权重更大
│   └── 梯度合成 → G = sqrt(Gx² + Gy²) 或 G = |Gx| + |Gy|
│
├── 二阶导数（变化率的变化率）
│   └── Laplacian 算子 → 直接检测边缘，但对噪声敏感
│
└── 应用场景
    ├── 边缘检测的前置步骤
    ├── 图像锐化
    └── 特征提取
```

## 三、核心概念

### 3.1 Sobel 算子

- **定义**: 一阶离散微分算子，计算图像亮度函数的梯度近似值
- **水平核**（检测垂直边缘）和**垂直核**（检测水平边缘）

```
Sobel-X (水平梯度):        Sobel-Y (垂直梯度):
┌──────────┐              ┌──────────┐
│ -1  0  1 │              │ -1 -2 -1 │
│ -2  0  2 │              │  0  0  0 │
│ -1  0  1 │              │  1  2  1 │
└──────────┘              └──────────┘
```

**核心思想**: 左边像素减右边像素（X方向），下边像素减上边像素（Y方向）

### 3.2 梯度计算方法

| 方法 | 说明 | 效果 |
|------|------|------|
| 分别计算 | 单独算 Gx 和 Gy | 可分别查看水平和垂直边缘 |
| 合并计算 | `cv2.Sobel(dx=1, dy=1)` | **不推荐**，效果差 |
| 合成梯度 | `G = |Gx| + |Gy|` 或 `sqrt(Gx²+Gy²)` | 推荐，得到完整边缘 |

### 3.3 Scharr 算子

- **定义**: Sobel 的增强版，核权重更大，对细小边缘更敏感
- **何时用**: 当 Sobel 检测到的边缘不够明显时

```
Scharr-X:                 Scharr-Y:
┌──────────┐              ┌──────────┐
│ -3  0  3 │              │ -3 -10 -3│
│ -10 0 10 │              │  0   0  0│
│ -3  0  3 │              │  3  10  3│
└──────────┘              └──────────┘
```

### 3.4 Laplacian 算子

- **定义**: 二阶导数算子，对像素值变化的"加速度"敏感
- **特点**: 对噪声极其敏感，通常需要先做高斯滤波
- **核**: 中心为 4 或 8，周围为 -1

```
Laplacian 核:
┌──────────┐
│  0  1  0 │
│  1 -4  1 │
│  0  1  0 │
└──────────┘
```

### 3.5 原理深入：梯度 vs 边缘

**梯度不是边缘，梯度大是边缘**。用一张图理解：

```
像素值剖面:        一阶导数(梯度):     二阶导数:
  ██                         ┌─┐
  ██                         │ │
  ██  ← 边缘            ─────┘ └─────    ──┐  ┌──
  ██                    平坦区  峰值区       │  │
  ██                                       └──┘
  █████████████████                      过零点 = 边缘位置
```

- **一阶导数**: 边缘处出现峰值（Sobel 的思路）
- **二阶导数**: 边缘处过零点（Laplacian 的思路）

**为什么 Laplacian 对噪声敏感？**

二阶导数 = "变化率的变化率"，噪声本身就是高频的随机变化，经过二阶导数后噪声会被放大：

```
信号:     [100, 105, 101, 200, 198, 102]  ← 中间有边缘
一阶导数:  [  5,  -4,  99,  -2, -96]
二阶导数:  [ -9, 103, -101, -94]  ← 噪声被放大！
```

### 3.6 原理深入：Sobel 为什么有两个核？

**为什么需要 Gx 和 Gy 两个方向？**

Sobel-X 检测垂直边缘，Sobel-Y 检测水平边缘。一张图可能同时有水平和垂直边缘，需要两个方向分别检测后合成：

```
合成梯度幅值: G = sqrt(Gx² + Gy²)
合成梯度方向: θ = arctan(Gy / Gx)
```

**代码中注意事项**：

- `cv2.Sobel` 的 `ddepth` 参数通常设为 `cv2.CV_64F`（浮点型），因为梯度可能有负值
- 取绝对值: `cv2.convertScaleAbs()` 将负值转正
- 如果用 `cv2.CV_8U`（uint8），负值会被截断为 0，丢失一半边缘信息

## 四、核心 API

| API | 函数签名 | 功能 | 关键参数 |
|-----|----------|------|----------|
| `cv2.Sobel()` | `Sobel(src, ddepth, dx, dy, ksize)` | Sobel 梯度 | ddepth=CV_64F, ksize=3/5/7 |
| `cv2.Scharr()` | `Scharr(src, ddepth, dx, dy)` | Scharr 梯度 | 固定 ksize=3 |
| `cv2.Laplacian()` | `Laplacian(src, ddepth, ksize)` | Laplacian 梯度 | 通常先做高斯滤波 |
| `cv2.convertScaleAbs()` | `convertScaleAbs(src)` | 取绝对值转 uint8 | 梯度值转可视化 |

## 五、代码实战

### 5.1 Sobel 算子

```python
import cv2
import numpy as np

img = cv2.imread("lena.jpg", cv2.IMREAD_GRAYSCALE)

# 分别计算水平和垂直梯度（注意 ddepth=CV_64F）
sobel_x = cv2.Sobel(img, cv2.CV_64F, dx=1, dy=0, ksize=3)
sobel_y = cv2.Sobel(img, cv2.CV_64F, dx=0, dy=1, ksize=3)

# 取绝对值转 uint8 用于显示
sobel_x_abs = cv2.convertScaleAbs(sobel_x)
sobel_y_abs = cv2.convertScaleAbs(sobel_y)

# 合成梯度（两种方式）
sobel_combined = cv2.addWeighted(sobel_x_abs, 0.5, sobel_y_abs, 0.5, 0)

res = np.hstack((img, sobel_x_abs, sobel_y_abs, sobel_combined))
cv2.imshow("Original | X | Y | Combined", res)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 5.2 Scharr 算子

```python
# Scharr 比 Sobel 对边缘更敏感
scharr_x = cv2.Scharr(img, cv2.CV_64F, dx=1, dy=0)
scharr_y = cv2.Scharr(img, cv2.CV_64F, dx=0, dy=1)
scharr_x_abs = cv2.convertScaleAbs(scharr_x)
scharr_y_abs = cv2.convertScaleAbs(scharr_y)
scharr_combined = cv2.addWeighted(scharr_x_abs, 0.5, scharr_y_abs, 0.5, 0)
```

### 5.3 Laplacian 算子

```python
laplacian = cv2.Laplacian(img, cv2.CV_64F, ksize=3)
laplacian_abs = cv2.convertScaleAbs(laplacian)

# 三算子对比
res = np.hstack((sobel_combined, scharr_combined, laplacian_abs))
cv2.imshow("Sobel | Scharr | Laplacian", res)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 5.4 效果对比

| 参数设置 | 效果描述 | 适用场景 |
|----------|----------|----------|
| Sobel ksize=3 | 基础边缘检测，边缘较粗 | 通用场景 |
| Sobel ksize=5 | 抗噪更强，但边缘更粗 | 噪声较大的图像 |
| Scharr | 边缘更精细，弱边缘也能检测 | 细节丰富的图像 |
| Laplacian | 边缘清晰但对噪声敏感 | 需先做高斯滤波 |

## 六、调试经验与避坑指南

| 问题现象 | 原因 | 解决方案 |
|----------|------|----------|
| Sobel 边缘只有一半 | ddepth 用 CV_8U，负值被截断 | 用 CV_64F，再用 convertScaleAbs |
| 合并 dx=1,dy=1 效果差 | 两个方向同时算效果不好 | 分别计算后合成 |
| Laplacian 全是噪点 | 没有先做模糊处理 | 先 `GaussianBlur` 再 `Laplacian` |
| 梯度图像一片黑 | 忘记取绝对值 | 用 `convertScaleAbs` |

### 常见坑点
- **坑点1**: `ddepth=-1` 表示和输入同类型，但对于梯度计算这意味着负值丢失 → 始终用 `cv2.CV_64F`
- **坑点2**: Sobel 的 `dx` 和 `dy` 不能同时设为 1 且 ksize 为特殊值 → 分别计算 Gx 和 Gy 后合成
- **坑点3**: Laplacian 直接用于原图 → 噪声被放大，先做高斯滤波

- **必掌握**: Sobel 梯度计算流程（CV_64F → convertScaleAbs → 合成）、Sobel 和 Scharr 的选择
